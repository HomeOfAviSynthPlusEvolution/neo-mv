# OcclusionMask：从相邻向量收敛构造事件区域

## 1. 这个函数计算什么

`OcclusionMask` 比较相邻块的水平或垂直向量分量。前一个块的分量大于后一个块时产生收敛事件，把事件强度写入一段网格区间。重叠事件取最大值，最后扩展到像素。

它表示这个计算定义下的向量收敛，不逐像素判断哪个物体真实遮住了另一个物体。SAD 只用于先前的场景判定。

## 2. 计算对象与记号

块步长 sx、sy，pel p，保存的有符号 delta 为 d。共享 `f=1/ml`、时间系数 t、最大值 M 和 Q 见 [共同规则](shared/mask-input.md)。初始块网格 G 全零。

## 3. 总体计算流程

判定可用性；计算水平相邻事件；计算垂直相邻事件；每格取所有覆盖事件的最大量化贡献；[重采样](shared/grid-resampling.md) 得到图像。不可用时填 scval。

## 4. 逐步计算

水平常量为 `hx=trunc(16t/(sx·p))`、`ax=fl32(fl32(80f)/fl32(sx·p))`，垂直对应 hy、ay。

对相邻 `(bx,by)` 和 `(bx+1,by)`，令 `o=vx左-vx右`。o≤0 没有事件；o>0 时 `k=trunc(o·hx/4096)`，目标列区间为：

$$[l,r]=\begin{cases}[\max(0,b_x+1-k),b_x+1]&d>0\\[b_x,\min(b_x+1-k,N_x-1)]&d\le0.\end{cases}$$

两端包含。如果 l>r，事件为空，直接丢弃，不能交换端点。对非空事件，以 a=ax 计算：

$$L=\begin{cases}fl32(fl32(M\,fl32(o))a)&\gamma=1\\fl32(M\,pow32(fl32(fl32(o)a),\gamma))&\gamma\ne1.\end{cases}$$

每个目标格更新 `G=max(G,Q(L))`。gamma=1 的乘法分组也保留，不任意重排。

垂直事件用上下 vy 之差，替换成 by、Ny、hy、ay，在同一列写行区间。不会跨行尾比较水平邻居，也不会跨列底比较垂直邻居。最后一行仍可有水平事件，最后一列仍可有垂直事件。

## 5. 一个完整的数值例子

GRAY8、两块 `4×4` 横排、无重叠、p=1、d=-1，向量 X 为 `[4,0]`，Y 和 SAD 为零，padding 足以容纳向量。ml=80、gamma=1、time=100。

f=1/80，t=256，hx=1024，o=4，所以 k=1，区间 `[0,0]`。ax=0.25，L=255，块网格为 `[255,0]`。重采样后每行是 `[255,255,223,159,96,32,0,0]`。

若只把 d 改为正，区间 `[0,1]`，网格全 255。若 d 仍负但 o=8，则 k=2，区间 `[0,-1]` 为空，网格全零；收敛差更大不保证覆盖更多格。

## 6. 参数与计算步骤对照

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `vectors` | 必需 | 相邻向量差和 delta 方向 |
| `ml` | 100.0，有限正 | 事件强度归一化 |
| `gamma` | 1.0，有限非负 | 强度幂变换 |
| `time` | 100.0，0～100 | 区间长度系数 |
| `scval` | 0.0 | 不可用场填充值 |
| `thscd1,thscd2` | 400、51.0 | 场景判定 |
| `prefix` | `MVUtensils` | 分析属性 |

## 7. 边界、缺失数据与错误

time=0 令 k=0，不消除事件：正 d 写右邻格，非正 d 可写当前与右邻两个格。d=0 使用非正分支，不请求参考图像。gamma=0 只使实际非空事件贡献 M，没有事件的格仍为零。

非有限贡献和完整损坏数据报错；缺失或不可用场填 scval。输出只含 `_Range=[1]`。

## 8. 数值精度与结果确定性

区间乘积和差使用宽整数；每事件先 Q 量化再取最大。水平垂直贡献不相加，交叉处不会因为两个满值事件而得到双倍强度。
