# DepanAnalyse：通过迭代拟合提取全局运动

## 1. 这个函数计算什么

`DepanAnalyse` 将多个块的位移作为观测，通过有限次迭代拟合平移、缩放和旋转，导出五个 Depan 属性。clip 像素不参与拟合；info=false 时原样保留。

它不是一次任意精度的最小二乘求解。初始化、步长、重新选权和停止条件都影响最终数值。

这里的块误差指存储的 `AnalysisSAD`，可能包含 SAD、SATD、DCT 或混合亮度误差，以及启用的色度 SAD。本函数不重算像素 SAD，也不在度量间换算；现有阈值和缩放公式直接作用于存储值。见[公共分析数据](shared/analysis-data.md)。

## 2. 计算对象与记号

创建时向量 delta 只能为 ±1，记为 d。d=+1 时输出 n 读取 vectors[max(0,n-1)]，d=-1 时读取 vectors[n]。固定分析 prefix 为 `MVUtensils`，无 prefix 参数。

像素宽高比 `a=pixaspect/(fields?2:1)`，中心 `cx=fl32(clip宽)/2,cy=fl32(clip高)/2`。每块观测为中心 `(Xi,Yi)`、像素位移 `(dxi,dyi)`、原始 SAD 与 mask 基权 mi。

## 3. 总体计算流程

保存创建时场景阈值与 d；按当前向量帧自身元数据解码；生成块中心与位移；初始化模型和权重；迭代拟合并重新选权；严格按残差判断好坏；按 d 选择直接转换或求逆，最后处理场位移并写属性。

## 4. 逐步计算

### 4.1 观测与场景准入

场景数值阈值 T1、T2 创建时按 [SCDetection](sc-detection.md) 计算并保存。当前帧可以有不同合法网格、位深等描述；数组长度和向量界限用当前描述，但坏块仍与保存的 T1 比较，坏块数仍与保存的 T2 比较，不重新缩放。

当前元数据无效或数组缺失则不拟合；完整损坏数组报错。保存的 d 决定选帧和最终转换方向，当前 delta 即使改变或缺失为零也不覆盖它。

中心为 `Xi=bx(Bx-Ox)+floor(Bx/2)`，Y 同理，不加 padding。位移为 `fl32(fl32(vx)·fl32(1/p))`，p 取当前分析值。

若提供 mask，它是与 clip 同尺寸、足够帧数、全分辨率首平面的 8 位整数图像；块中心在其范围内时 mi 取该字节，超出则 mi=1。没有 mask 时 mi=1。数值 128 就是权重 128，不除以 255。初始权重 bi=mi，首轮之前不做边缘或坏块剔除。

### 4.2 一次更新

初始化 `tx=ty=v=w=0,u=h=1,E=2·error,iter=0`。对当前旧映射计算残差：

$$e_{xi}=(((t_x+uX_i)+vY_i)-X_i)-dx_i,$$
$$e_{yi}=(((t_y+wX_i)+hY_i)-Y_i)-dy_i.$$

按块行序累加 N、X2、Y2、R，每个初值均为 binary32 的 0.1，依次加 bi、`fl32(Xi²)bi`、`fl32(Yi²)bi`、`(exi²+eyi²)bi`。0.1 是运算的一部分，零权重时也不消失。

从 +0 按同样顺序累加梯度分子，然后：

$$g_x=\frac{\sum(2e_x)b}{2N},\quad g_y=\frac{\sum(2e_y)b}{2N},$$
$$g_{xx}=\frac{\sum(2X)e_xb}{(2X2)1.5},\quad g_{yy}=\frac{\sum(2Y)e_yb}{(2Y2)1.5},$$
$$g_{xy}=\frac{\sum(2Y)e_xb}{(2Y2)3},\quad g_{yx}=\frac{\sum(2X)e_yb}{(2X2)3}.$$

本轮不启用缩放时 xx/yy 分子保持零，不求相应项；不启用旋转时 xy/yx 同理，但零分子的除法仍执行。分子逐项从左到右乘，Xi²、2Xi 先精确整数计算。

步长为 s 时，残差标量 `E'=sqrt(R/N)`，同步更新：

$$t'_x=t_x-sg_x,\quad t'_y=t_y-sg_y,$$
$$u'=u-(s\cdot0.5)(g_{xx}+g_{yy})\quad\text{（启用缩放时）},\quad h'=u',$$
$$v'=v-(s\cdot0.5)(g_{xy}-g_{yx}/(a^2)),\quad w'=((-a)a)v'.$$

未启用缩放时 u 保持。xy 更新即使旋转禁用也按零梯度执行。E' 反映更新前旧映射的残差，不是新映射重新测量的误差。

### 4.3 更新后怎样重新选权

按次序检查，遇到首个失败就令 bi=+0，后面的算术不再执行：

1. 无 mask 时剔除四周各四个块；有 mask 时不作这个边缘剔除。
2. SAD>T1。
3. 有完整八邻居时，dx 与八邻居平均差绝对值>wrong。
4. 同样检查 dy。
5. 新模型水平残差绝对值>G。
6. 新模型垂直残差绝对值>G。

八邻居均值顺序为左上、上、右上、左、右、左下、下、右下，使用原观测，不使用其权重。边缘没有八邻居就跳过这两项。通过后，零位移观测使用 `zerow·mi`，其他为 mi。

每轮重新从原观测选权，剔除不是永久性的。wrong、zerow 允许有限负数，其后果按比较与算术实际发生；若导致非法 R/N 等数值则报错。

### 4.4 更新日程与停止

前五次 k=0…4 固定 s=0.3，只拟合平移，每次随后以 G=1000 选权，不因 E 小而提前结束。

k=5…99 按用户 zoom/rot 启用对应项。k<8 用 s=0.3，8≤k<10 用 0.6，之后用 1。更新后若 `(Eold-E'<0.005 且 k>9)` 或 `E'<0.01`，保存新模型并以 iter=k 停止，不再选权；否则以 G=2E' 重新选权。99 轮完成还未停止时 iter=100。

### 4.5 有效性和运动输出

最终仅以 `E<error` 判断有效。无可用输入时保留初始 E=2error 和单位映射，也仍做这个比较，所以 error<0 时该分支可能判有效；不能额外要求“拟合执行过”。

无效输出标准 `(0,0,0,1,0)`。有效时 d=-1 将模型按 forward=true 转回运动；d=+1 先作 [特定逆变换](shared/global-motion.md)，再按 forward=false 转回。不是简单反转 dx/dy。

有效且 fields=true 时，从 clip[n] 或 tff 取得场奇偶，top 给 dy 加 1，bottom 减 1。不读取向量载体的场信息。info=true 写诊断并调用文本渲染器；其余属性来自 clip[n]。

## 5. 一个完整的数值例子

clip 为 `16×16`，旧分析 `2×2` 个 `8×8` 块，所有向量和 SAD 为零，d=-1，提供全零 mask，所有块中心在 mask 内，fields=false、error=15。

初始及随后权重都为零。每次 N=X2=Y2=R=0.1，梯度为零，模型保持单位，E=sqrt(1)=1。前五轮照常执行，之后直到 k=10 满足改进量不足，iter=10。1<15，所以导出有效单位运动；像素保持原样。

把 error 改为 1，严格比较不通过，输出无效元组。这个例子说明全零权重不自动等于无效；正则初值、停止条件和最终比较共同决定结果。

## 6. 参数与计算步骤对照

| 参数 | 默认与约束 | 作用 |
| --- | --- | --- |
| `clip,vectors` | 必需；clip 固定格式/尺寸，vectors 足够长 | 输出与观测，clip 可为 RGB/float |
| `mask` | 省略 | 8 位基权与边缘剔除模式 |
| `zoom,rot` | true、true | 第五次以后拟合项 |
| `pixaspect` | 1.0；有限正 | 模型纵横关系 |
| `error` | 15.0；有限 | 初始化和严格接受阈值 |
| `wrong` | 10.0；有限 | 八邻居异常阈值 |
| `zerow` | 0.05；有限 | 零位移观测权重倍率 |
| `thscd1,thscd2` | 400、51.0 | 保存的场景阈值 |
| `fields,tff` | false、省略 | 半 aspect 与最终 dy 修正 |
| `info` | false | `DepanAnalyse_info` 及文本渲染 |

## 7. 边界、缺失数据与错误

没有无条件的首帧无效规则，d=+1 在 n=0 仍读 vectors[0]。提供的 mask[n] 即使字段不可用也必须可取，但不可用时不读其拟合样本。a² 必须有限非零，必需除数非零，R/N 非负。数值失败报错，不变成普通无效运动。

## 8. 数值精度与结果确定性

所有拟合更新保留 binary32 运算顺序和旧状态依赖。迭代停止保留刚更新的新模型，E 却对应更新前残差。转换回运动时中心乘减仍会舍入，导出的 dx 不必与模型 tx 位级相等。
