# FlowFPS：精确映射输出时间轴，再进行双向插值

## 1. 这个函数计算什么

`FlowFPS` 先把每个输出帧编号转换为源帧位置，再决定复制端点还是执行 [双向插值](shared/bidirectional-interpolation.md)。帧率、帧数及每帧时长随之改变。

## 2. 计算对象与记号

源帧率 `Ri=I/J`，源帧数 Nv，目标帧率约分为 `P/Q`。源/目标帧率比约分为 `a/b`。向量对 `[bw,fw]` 距离 d>0，输出编号 n 对应左帧 l、右帧 r 和时间系数 t。

## 3. 总体计算流程

创建时约分帧率并算输出数量；逐帧精确计算 l，再量化小数时间；t 为端点时直接复制原图，否则选运动插值或原图回退；所有成功分支最后改写时长属性。

## 4. 逐步计算

### 4.1 输出帧率与帧数

num、den 独立默认为 25、1，均须非负。两者都正时目标率为 num/den；任意一个为零时目标率为 `2Ri`，不是使用默认值。

用精确整数约分得到 P/Q 及 a/b，各个约分结果须在正 int64 范围内。未约分乘积大不应单独导致失败。输出数：

$$N_o=\lfloor N_vb/a\rfloor.$$

不向上取整，不额外增加末端帧，结果须为 1～2147483647。

### 4.2 源位置和时间系数

左帧 `l=floor(n·a/b)` 用精确整数算出，右帧 `r=l+d`。再按下面的 binary64 步骤量化相对时间：

$$u=fl64(fl64(fl64(n)fl64(a))/fl64(b)),\quad e=fl64(u-fl64(l)),$$
$$t_0=trunc(fl64(fl64(e\cdot256)+0.5)),\quad
t=\begin{cases}trunc(t_0/d)&d>1\\t_0&d=1.\end{cases}$$

l 不因浮点 u 的舍入而改变。t0 必须为 0～256，不夹非法值；合法的 256 保留。除以 d 在量化之后，不能先除完整源位置或替换成另一套有理数舍入。

### 4.3 分支顺序

t=0 复制 clip[min(l,Nv-1)]；t=256 复制 clip[min(r,Nv-1)]。端点不读取当前向量数组或 Super，blend/extramask 不改变这个选择，但创建时几何检查仍必要。

其他 t 先选择主字段 bw[l]、fw[r]；extramask=true 才尝试额外字段。可用时执行共享插值；越界或主场不可用时，blend=true 混合被夹到末帧以内的左右 clip，blend=false 复制左 clip。

非端点属性来自左 clip。每个分支最后都替换 `_DurationNum=[Q]`、`_DurationDen=[P]`，其他属性保持不变，包括场景标记。

## 5. 一个完整的数值例子

源为三帧、24fps，目标 num=48,den=1，d=1。`a/b=1/2`，No=6。

输出 n=1：l=0,r=1,u=0.5,t=128。若主场零向量可用、额外场缺失、Super 常量为 10 和 21，普通插值得到整数 15，属性从 clip[0] 来，时长改为 1/48。

输出 n=2：l=1,t=0，直接复制 clip[1]，即使 Super[1] 像素不同或本帧向量数组损坏也不读取它们。输出 n=5：l=2,r=3,t=128，右侧越界，按 blend 复制或混合末帧。三种分支时长都为 1/48。

## 6. 参数与计算步骤对照

| 参数 | 默认与约束 | 作用 |
| --- | --- | --- |
| `clip,super,vectors` | 必需；原始 Nv 上匹配 | 时间轴、样本和向量对 |
| `num,den` | 25、1；非负 int64 | 目标帧率，任一零为源率翻倍 |
| `extramask` | true | 是否读取额外字段 |
| `ml` | 100.0；binary32 有限正数 | 遮挡强度 |
| `blend` | true | 非端点不可用主场的原图混合 |
| `thscd1,thscd2` | 400、51.0 | 场景判定 |
| `prefix` | `MVUtensils` | 数据名称 |

## 7. 边界、缺失数据与错误

需要已知正源帧率，输出零帧是创建错误。num=-1 即使 den=0 也非法。辅助长度匹配源 Nv，不是输出 No。extramask=false 完全取消额外字段依赖；端点分支不同于 FlowInter，不进行插值验证。

## 8. 数值精度与结果确定性

帧率约分、数量和 l 使用精确整数，小数时间使用明确的 binary64 运算。例如源 24fps、目标 30fps，n=1 得 t0=205；d=2 时再截为 102。源 1fps、目标 1000fps、n=999 得 t=256，必须进入右端点复制，不能限制为 255。
