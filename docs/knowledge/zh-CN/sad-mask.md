# SADMask：投影块误差并生成灰度

## 1. 这个函数计算什么

`SADMask` 使用当前块的运动向量选择小网格中另一个块的存储误差，再把该误差归一化为灰度。它不读取图像，也不在投影位置重新测量 SAD。

这里的块误差指存储的 `AnalysisSAD`，可能包含 SAD、SATD、DCT 或混合亮度误差，以及启用的色度 SAD。本函数不重算像素 SAD，也不在度量间换算；现有阈值和缩放公式直接作用于存储值。见[公共分析数据](shared/analysis-data.md)。

## 2. 计算对象与记号

块步长 `sx=Bx-Ox,sy=By-Oy`，pel 为 p，分析精度为 ba。`f,t,M,Q` 来自 [mask 共同规则](shared/mask-input.md)。

## 3. 总体计算流程

判定场可用性，计算每块误差来源索引，把选中误差按位深和块面积换算，经过 gamma 与量化，再 [重采样](shared/grid-resampling.md)。不可用时直接填 scval。

## 4. 逐步计算

创建时：

$$h_x=trunc\frac{(256-t)16}{s_xp},\quad h_y=trunc\frac{(256-t)16}{s_yp},\quad
a=fl32\left(\frac{fl32(4f)}{fl32(B_xB_y)}\right).$$

对当前块 `(bx,by)`，用它自己的向量计算：

$$i=b_x-trunc(v_xh_x/4096),\quad j=b_y-trunc(v_yh_y/4096).$$

若任一轴越出网格，两个轴一起恢复成当前块索引。这不是分别夹坐标。例如 i 合法但 j=-1 时，读取当前块，不读取第 i 列当前行。

取选中块原始误差 S，先按分析位深降到较接近 8 位的整数尺度：

$$s=\left\lfloor S/2^{\min(16,b_a)-8}\right\rfloor,\quad z=fl32(fl32(s)a),$$
$$L=fl32(M\,pow32(z,\gamma)),\quad G(b_x,b_y)=Q(L).$$

float32 分析也使用八位右移，因为它的错误值已经整数编码。色度是否参与分析不增加额外除数，只在场景判定中影响阈值。

## 5. 一个完整的数值例子

GRAY8 单个 `8×8` 块、p=1、零向量、SAD=8，ml=1、gamma=1、time=100，场景判断通过。t=256，所以 hx=hy=0，取自身误差；a=4/64=1/16，z=8/16=0.5，L=127.5，截断成 127。单块重采样得到全幅 127。

投影的例子：横向三个无重叠的 4×4 块，误差 `[0,4,8]`，中块向量 `(4,0)`，其他零向量。ml=1、gamma=1、p=1，time=0 时 hx=1024，中块取左块的误差 0，量化网格 `[0,0,255]`；time=100 时不投影，网格为 `[0,255,255]`。

## 6. 参数与计算步骤对照

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `vectors` | 必需 | 向量决定投影，SAD 提供得分 |
| `ml` | 100.0，有限正 | 误差归一化 |
| `gamma` | 1.0，有限非负 | 幂变换 |
| `time` | 100.0，0～100 | 通过 `256-t` 控制投影距离 |
| `scval` | 0.0 | 不可用场填充值 |
| `thscd1,thscd2` | 400、51.0 | 场景判定 |
| `prefix` | `MVUtensils` | Analysis 名称 |

## 7. 边界、缺失数据与错误

网格投影越界回到自身，但损坏输入不会触发这个分支而被掩盖。完整负 SAD 报错，缺失数组则整幅填 scval。无需检查参考帧编号是否存在。输出属性仅为 `_Range=[1]`。

## 8. 数值精度与结果确定性

投影乘除向零取整，位深除法向下取整，得分 Q 再截断。例如 `vx=-1,hx=1024` 时投影偏移为零，不能改用 floor 得到 -1。所有像素来自量化后的网格，不能用未量化得分直接插值。
