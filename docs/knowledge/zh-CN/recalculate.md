# Recalculate：把旧向量映射到新网格并重新测量

## 1. 这个函数计算什么

`Recalculate` 接收旧分析节点数组，将每个成员的向量映射到新的块网格，在新的 Super 样本上重新计算误差，必要时进一步搜索。返回节点数及顺序与输入数组一致。

旧误差只接受数据有效性检查，不决定是否搜索。即使向量完全不动，输出误差也重新测量。可见输出与初始属性来自 `super`，不来自旧向量节点。

### 混合度量的权重

两个 local 模式使用与 [Analyse](analyse.md) 相同的逐候选门限和 Q16 加权公式，参数独立于输入矢量，省略时分别为 0.5 和 0.03125。三个 global 模式在 Recalculate 中固定 base_weight=8，half 模式实际用 4；没有最粗层统计。先按该模式重新测量映射来的候选，再将新的原始误差与 thsad 比较；旧矢量的存储误差不参与混合。

## 2. 计算对象与记号

旧几何带下标 0，包括块 `Bx0,By0`、步长 `sx0,sy0` 和 `p0`。目标几何为 `Bx,By,Ox,Oy,p`，目标块索引为 `bx,by`。`d` 是成员创建时保存的旧 `DeltaFrame`。

每次计算取 `vectors[n],super[n]` 和 `super[k]`，其中 `k=clamp(n+d,0,Nsuper-1)`。越过序列边界时比较首/末帧，不走 `Analyse` 的缺失参考分支。

## 3. 总体计算流程

建立目标网格与可采样候选域；解码旧向量；按目标块中心在旧网格中最近选择或插值；换算 pel 并限制到目标域；重新测误差；超过阈值才搜索；输出新网格和新误差。

## 4. 逐步计算

### 4.1 目标几何

目标网格使用 [Analyse](analyse.md) 最细层的向上取整覆盖公式。块原点 `x=bx(Bx-Ox),y=by(By-Oy)`，候选域为：

$$-p(x+h_p)\le v_x<p(W+h_p-x-B_x),$$
$$-p(y+v_p)\le v_y<p(H+v_p-y-B_y).$$

整个整数域都必须可采样，不能因为本次误差较低、可能不搜索而省略检查。这里没有 Ω 外的特殊零种子。

### 4.2 目标中心落在旧网格哪里

水平中心及旧网格索引为：

$$c_x=\lfloor B_x/2\rfloor+(B_x-O_x)b_x,$$
$$j_x=\operatorname{trunc}\frac{c_x-\lfloor B_{x0}/2\rfloor}{s_{x0}},\quad
d_x=\max(0,c_x-(\lfloor B_{x0}/2\rfloor+s_{x0}j_x)).$$

垂直同理。取旧网格 `(jx,jy),(jx+1,jy),(jx,jy+1),(jx+1,jy+1)` 的向量为 `A,B,C,D`，每个索引独立夹到旧边界。必须先算 `dx,dy`，再夹查找索引。

这个映射使用各自声明的块中心坐标，旧图尺寸与新图尺寸不同不会自动触发图像比例缩放。外部旧块即使尺寸为奇数，半块仍向下取整。

### 4.3 最近选择与平滑插值

`smooth=false` 时，若 `2dx<sx0` 取左，否则取右；若 `2dy<sy0` 取上，否则取下。正好居中选择右/下。

`smooth=true` 对 X、Y 分量各自计算：

$$u=A s_{x0}+d_x(B-A),\quad v=C s_{x0}+d_x(D-C),$$
$$I=\operatorname{trunc}\left(\frac{u+\operatorname{trunc}(d_y(v-u)/s_{y0})}{s_{x0}}\right).$$

先沿两行得到横向加权量，再沿纵向插值；两次向零取整都保留。选中或插值出的分量 `z` 再换算为 `floor(z·p/p0)`，最后夹到 Ω 的包含端点。例如 `z=-1,p0=2,p=1` 得到 -1，不是零。

### 4.4 阈值、重测与搜索

新误差使用 [Analyse 中的 SAD、SATD、DCT 和混合误差计算](analyse.md#45-从样本计算原始误差)。`metric` 独立默认为 `"sad"`，不会继承输入向量生成时使用的度量；若要重新测量 DCT，须显式传入 `metric="dct"`。DCT 要求整数样本，支持全部合法目标块尺寸。下面的阈值缩放规则保持不变，不在度量之间自动换算。

使用 [Analyse](analyse.md) 中的位深转换 `Qb`：

$$\lambda_0=Q_b(\operatorname{trunc}(mvlambda\,B_xB_y/64)),\quad
T=\operatorname{trunc}(Q_b(thsad)\,B_xB_y/64).$$

启用色度后 `T←T+2·trunc(T/(rx·ry))`，先除法取整再乘 2。第一块行 `λ=0`，其余行 `λ=floor(λ0/p²)`。

在映射位置 `u` 重新测 `s(u)`。若 `s(u)≤T`，直接输出这个位置及新误差；否则以位置 `u`、初始比较代价 `s(u)`、固定预测 `u` 开始搜索，使用 `q=pnew`、范围 `max(1,searchparam)`。候选生成和代价见 [Analyse 的搜索说明](analyse.md)。

这里不做 LSAD 自适应、层级乘子、全局预测、多起点或坏块扩展。负阈值使所有非负误差都进入搜索，但搜索仍需要严格改进才能改变位置。

## 5. 一个完整的数值例子

旧块为无重叠 `8×8`，目标首块为 `16×8`。水平中心为 8，旧首块中心为 4，因此 `jx=0,dx=4,sx0=8`。若旧左右 X 向量为 0、4，且上下两行相同：最近选择因居中取右而得到 4；平滑插值得到 2。

设目标和旧 pel 都为 1，向量 2 在目标域内，GRAY8 目标新误差为 100。取 `thsad=50`，面积 128，使 `T=100`。因为比较为 `≤`，不继续搜索，输出向量 2、误差 100。即使旧误差为 999，结果也不受它影响。目标元数据的 `Levels` 写为 1。

## 6. 参数与计算步骤对照

| 参数 | 默认与约束 | 作用 |
| --- | --- | --- |
| `super`,`vectors` | 必需；vectors 非空节点数组 | 新样本与旧网格 |
| `thsad` | 200；有符号 int32 | 新误差是否需要搜索 |
| `smooth` | true | 旧网格最近选择或插值 |
| `blksize`,`overlap` | 继承 Super | 目标网格，数组规则同 Analyse |
| `search`,`searchparam` | 2、2；search 为 0～5，范围至少 1 | 单层搜索 |
| `mvlambda`,`pnew` | 1000、25；分别非负、0～256 | 距离和误差惩罚 |
| `chroma` | true | 是否计入色度 SAD |
| `metric` | 默认 `"sad"`；SATD 家族要求尺寸能被 4 整除；DCT 和混合模式仅整数 | 亮度误差策略，色度仍用 SAD |
| `metric_weight` | local 专用，默认 0.5，[0,1] | 触发后的变换比例，Q16 量化 |
| `metric_threshold` | local 专用，默认 1/32，[0,1] | 相对亮度和变化门限，Q16 量化 |
| `meander` | true | 求值方向，不改变独立块结果 |
| `fields`,`tff` | false、省略 | 场信息验证 |
| `prefix` | `MVUtensils` | Super 和 Analysis 名称 |

## 7. 边界、缺失数据与错误

旧精度须与新 Super 相同，但旧块、网格、pel 和实际尺寸可以不同。有效元数据但数组缺失或长度不符时，用全零旧向量进行映射、重测和搜索；完整但损坏的数组报错。公共数据状态见 [分析数据与场景判定](shared/analysis-data.md)。

创建时固定每个成员的 `d`，后续属性变化不能改变参考帧和输出 delta。违反已建立几何或精度条件的变化报错。任一成员创建失败使整个调用失败。

`fields=true` 要求旧 `AnalysisPel>1`；当前场信息必须有效，目标 pel 大于 1 且 `d` 为奇数时也检查被夹到序列内的参考场。这个验证不额外给映射向量加半像素位移。

## 8. 数值精度与结果确定性

插值中的向零取整与 pel 换算的向下取整不可合并。旧误差不参与插值或面积换算。每个目标块只依赖旧数据和新图像，所以 `meander` 不像 Analyse 那样改变空间预测结果；并发次序不改变输出。
