# SCDetection：从块误差计算场景标记

## 1. 这个函数计算什么

`SCDetection` 不读取参考图像，也不重新计算运动。它把向量帧中的原始块误差与两个阈值比较：先判断每块是否为坏块，再判断坏块数量是否足够多。

输出保留 `clip` 的像素，只替换一个方向的场景属性。分析精度来自向量元数据，与承载输出的 clip 位深无须相同。

这里的块误差指存储的 `AnalysisSAD`，可能包含 SAD、SATD、DCT 或混合亮度误差，以及启用的色度 SAD。本函数不重算像素 SAD，也不在度量间换算；现有阈值和缩放公式直接作用于存储值。见[公共分析数据](shared/analysis-data.md)。

## 2. 计算对象与记号

块尺寸 `Bx,By`，网格 `Nx,Ny`，总块数 `N=NxNy`，色度比例 `rx,ry`，分析精度 `b`。`T1` 是单块误差阈值，`T2` 是坏块数量阈值，`K` 是实际坏块数。

## 3. 总体计算流程

创建时读取向量第 0 帧的描述信息并建立阈值；每帧验证分析数据状态及描述的一致性；对完整数组统计坏块；根据当前 delta 的方向写属性。

## 4. 逐步计算

### 4.1 单块阈值按什么尺度换算

`thscd1` 使用 8 位、`8×8` 的参考误差单位。换到当前分析尺度：

$$A=B_xB_y/64,\quad C_f=\begin{cases}1+2/(r_xr_y)&\text{使用色度}\\1&\text{否则}\end{cases},$$
$$D=(2^{\min(16,b)}-1)/255,\quad T_1=\lfloor thscd1\,((AC_f)D)+0.5\rfloor.$$

这些除法为 binary64 实数除法，面积乘积先精确算出。色度因子补上两个色度平面对应的面积比例；float32 分析使用 `D=257`，因为它的误差编码到 65535 尺度，不能改用样本最大值 1。

### 4.2 百分比怎样成为块数阈值

`thscd2` 先转换成 binary32，验证有限且为 0～100。再提升到 binary64，依次算 `((thscd2·Nx)·Ny)/100`，最后舍入为 binary32 的 `T2`。

`T2` 不取整成块数。例如四块、51% 得到 binary32 的 2.04，而不是 2，也不是把 51 当作 0～255 尺度。

### 4.3 两次严格比较

$$K=\sum_i\mathbf1_{SAD_i>T_1},\qquad change=\mathbf1_{binary32(K)>T_2}.$$

等于单块阈值不计入坏块，坏块数等于数量阈值不判场景变化。`SAD` 指导出的原始误差，可能包含亮度 SATD；这里不推断误差是怎样生成的。

### 4.4 写入哪个方向

当前有效 `DeltaFrame>0` 时写 `_SceneChangeNext=[change]`，否则写 `_SceneChangePrev=[change]`。这些键不加 `prefix`，另一方向的原属性连类型和元素数都保留。其他属性来自 `clip[n]`，不从向量帧复制。

## 5. 一个完整的数值例子

GRAY8、块 `8×8`、网格 `2×2`、`thscd1=400,thscd2=50`：`A=Cf=D=1`，所以 `T1=400,T2=2`。

误差 `[400,401,900,0]` 有两个严格超过 400，`K=2`，不严格超过 2，故 `change=0`。把首项改成 401，`K=3`，得到 1。

若 delta 为 2，输入 clip 的 Prev 是 `[7]`，Next 是 `[9,8]`，第二种情况下输出 Prev 仍为 `[7]`，Next 改为 `[1]`，像素不变。

## 6. 参数与计算步骤对照

| 参数 | 默认与约束 | 作用 |
| --- | --- | --- |
| `clip`,`vectors` | 必需节点 | 可见输出与分析数据 |
| `thscd1` | 400；int64，0～16320 | 单块误差阈值 |
| `thscd2` | 51.0；转换到 binary32 后有限且 0～100 | 坏块百分比 |
| `prefix` | `MVUtensils` | 只用于查找 Analysis 属性 |

## 7. 边界、缺失数据与错误

创建时需有合法元数据，但不需要第 0 帧已经有向量数组。逐帧无效元数据或有效元数据但无可用数组，得到 `change=1`；完整数组中的负误差、越界向量等损坏仍报错。具体解码见 [公共分析数据](shared/analysis-data.md)。

块尺寸、网格、布尔色度标记、色度比例和精度须与创建时一致，即使当前数组不可用，合法但变化的描述仍报错。无效元数据走不可用分支。

它不检查 `n+delta` 是否在 clip 内。外部生产的完整向量在边界也可以正常分类。`thscd2=100` 仅使完整数据不会超过阈值，不能屏蔽缺失数据产生的 1。

## 8. 数值精度与结果确定性

两次严格比较、百分比的 binary32 转换和不取整的块数阈值共同决定临界值结果。输出只依赖当前帧数据及固定描述，不积累前一帧的分类状态。
