# Compensate：逐块选择并采样参考图像

## 1. 这个函数计算什么

`Compensate` 根据每块的原始误差，在参考 Super 与当前 Super 之间选择样本来源，再按运动位移取整块，最后用重叠窗口合成。它不重新估计向量，也不按 SAD 连续混合两个图像。

## 2. 计算对象与记号

当前帧 `n`、保存的参考偏移 `d`、向量 `(vx,vy)`、误差 `s`。`t` 是时间百分比量化后的 0～256 系数；`T` 是缩放后的块误差阈值；`f` 是垂直场位移。

## 3. 总体计算流程

验证几何和当前 Super，解码向量并判定整帧参考可用性；可用时读取参考和必要场信息，检查实际采样脚印；逐块选择当前/参考 Super，采样后进行 [块合成](shared/block-rendering.md)。不可用时整帧返回 clip。

## 4. 逐步计算

### 4.1 时间与阈值

$$t=trunc(fl64(fl64(time\cdot256)/100)),\quad T=S(thsad).$$

`S` 是 [块渲染中的分析尺度转换](shared/block-rendering.md)，使用分析位深，不使用输出位深。

### 4.2 场位移

`fields=true` 要求 `p>1`。仅 `d` 为奇数时需要当前与参考场奇偶：提供 `tff` 则用 `top(k)=bool(tff) XOR (k 为奇数)`，否则读取 `_Field` 元素 0，非零表示 top。

当前 top、参考 bottom 时 `f=p/2`，反之 `f=-p/2`，否则零。偶数 d 或禁用 fields 时不读场属性，`f=0`。整帧参考不可用时也无需场信息。

### 4.3 每块取哪张图、哪个位置

若 `s<T`，取 `Super[n+d]`，位移为：

$$d_x=trunc(v_xt/256),\qquad d_y=trunc(v_yt/256)+f.$$

否则取 `Super[n]`，位移 `(0,f)`。等于阈值选择当前 Super。场位移加在时间缩放之后，不乘 `t`。

因此 `time=0` 仍可能从参考帧读取，只是运动位移归零；高误差选择当前块时仍可能有半像素场位移。两种情况都不能简化成复制 `clip[n]`。

### 4.4 采样与合成

使用 [总坐标向下取整的块采样](shared/block-rendering.md)，对实际所有渲染平面取样；分析未含色度也不代表跳过色度渲染。生成完整块后，按窗口合成并裁出可见图像。输出属性完全来自 clip，不改向量或场景属性。

## 5. 一个完整的数值例子

GRAY8 单个 `8×8` 块，无重叠，`p=1,pad=4,d=1`，当前 Super 常量 10，参考常量 80，clip 常量 5。`thsad=100`，无色度分析使 `T=100`，场景判断通过。

误差 99 时取参考，零向量得到 80；误差 100 时取当前 Super 得到 10。若向量数组缺失，整帧回退得到 clip 的 5。三个结果都保留 clip 属性。

在第一种情况下把 time 改为 0，结果仍为 80；时间参数没有把参考图像变成当前图像。

## 6. 参数与计算步骤对照

| 参数 | 默认与约束 | 计算作用 |
| --- | --- | --- |
| `clip,super,vectors` | 必需节点 | 输出描述、采样图像、分析场 |
| `thsad` | 10000；非负 int64 | 逐块二选一阈值，缩放后须可表示 |
| `fields` | false；启用要求 pel>1 | 场位移 |
| `time` | 100；有限 binary64，0～100 | 位移量化系数 |
| `thscd1,thscd2` | 400、51.0 | [场景判定](sc-detection.md) |
| `tff` | 省略 | 场奇偶来源 |
| `prefix` | `MVUtensils` | Super/Analysis 命名 |

## 7. 边界、缺失数据与错误

整帧回退发生于无效元数据、缺失数组、场景不通过或 `n+d` 越界；完整损坏数组、有效描述变化、当前 Super 无效仍报错。`d=0` 合法，可对当前 Super 作位移。

创建时验证整个公共向量域经过时间缩放后的采样安全性，以及所有可能的当前场位移。逐帧还检查每个实际参考向量加上实际 `f` 后的完整脚印，即使其 SAD 最后会选择当前块，也不能跳过检查。失败不转换成回退。

## 8. 数值精度与结果确定性

时间缩放向零取整，色度块采样总坐标向下取整，是不同步骤。例如 `vx=-3,time=50` 得 `dx=-1`。SAD 阈值、场位移、窗口量化各自独立，不能把整套运算改成线性图像混合。
