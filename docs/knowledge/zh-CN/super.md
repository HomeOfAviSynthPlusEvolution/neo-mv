# Super：建立工作图像、金字塔与亚像素相位

## 1. 这个函数计算什么

`Super` 为后续运算准备一组辅助图像：补齐块覆盖范围的工作图像、边缘扩展、逐层缩小的整数图像，以及最细层的亚像素采样相位。可见输出仍是输入图像，辅助图像不会替换画面。

“相位”表示固定的小数采样偏移。例如 `pel=2` 有整数、水平半像素、垂直半像素和双向半像素四张逻辑图像；下游根据向量选择相位和整数位置，不必每次重新插值。

## 2. 计算对象与记号

原始亮度尺寸为 `W,H`，块为 `Bx,By`，重叠为 `Ox,Oy`，亮度 padding 为 `px,py`。色度比例 `rx,ry` 表示一个色度像素对应多少亮度像素，GRAY 使用 1、1。

整数 b 位样本的最大值为 `M=2^b-1`，定义：

$$R_k(z)=\lfloor(z+2^{k-1})/2^k\rfloor,\quad K(z)=\min(M,\max(0,z)).$$

`Rk` 是带舍入的除法，`K` 把有符号滤波结果裁剪回样本范围。`A(a,b)=R1(a+b)` 是一次二点平均，`D(a,b,c,d)=R2(((a+b)+c)+d)` 是一次四点平均。float32 使用不加偏置的除法，不做 `K` 裁剪，每次运算舍入到 binary32。

## 3. 总体计算流程

1. 根据块步长计算工作尺寸与层数。
2. 把原图扩展到工作区域和外围 padding。
3. 从整数图像逐层缩小，再扩展每个新层的边缘。
4. 在最细层生成小数相位，或从外部 `pelclip` 提取它们。
5. 保留可见图像，附加描述几何的属性及辅助采样数据。

## 4. 逐步计算

### 4.1 块覆盖如何决定工作尺寸

块步长为 `sx=Bx-Ox,sy=By-Oy`。为使最后一个块完整存在，需要：

$$N_x=\left\lceil\frac{W-O_x}{s_x}\right\rceil,\quad W_0=N_xs_x+O_x,$$
$$N_y=\left\lceil\frac{H-O_y}{s_y}\right\rceil,\quad H_0=N_ys_y+O_y.$$

`W0,H0` 是工作尺寸。例如原图 `18×10`、块 `8×8`、重叠 `4×4`，得到 `4×2` 个块，工作尺寸 `20×12`。补出的区域通过最近边缘复制得到，不是重新缩放原图。

对平面比例 `ux,uy`，原始尺寸为 `W/ux,H/uy`，工作尺寸为 `W0/ux,H0/uy`，padding 为 `hp=floor(px/ux),vp=floor(py/uy)`。所以正亮度 padding 也可能对应零色度 padding。

### 4.2 层数与尺寸

单个维度缩小的规则为：

$$F(d,r,p)=r\left\lfloor\frac{\lfloor d/r\rfloor+\mathbf1_{p\ge r}}2\right\rfloor.$$

从实际亮度尺寸 `W,H` 出发，使用全局色度比例和亮度 padding 反复缩小，统计连续仍不小于块尺寸的缩小结果数 `t`，层数为 `max(1,t)`。不再给原图加一；`onelevel=true` 强制一层。例如 GRAY `64×64`、块 8、padding 16，候选 32、16、8 通过，4 不通过，所以存储三层，实际工作尺寸是 64、32、16。

各平面的第 0 层从自己的工作尺寸开始。下一层仍用 `F`，即使是 U/V，也使用全局 `rx,ry`，但传入该平面自己的 padding。padding 跨层保持不变。每层尺寸必须为正；生成下一层 `w',h'` 还要求 `2w'≤w+hp,2h'≤h+vp`，并满足滤波实际读取范围。

### 4.3 最近边缘扩展

对原始平面 `S`，实际尺寸 `w,h`，工作尺寸 `ww,hh`，整个带 padding 的输出为：

$$B(u,v)=S(\min(w-1,\max(0,u-h_p)),\min(h-1,\max(0,v-v_p))).$$

这一个式子同时处理左上 padding、右下工作扩展和右下 padding。所有扩展值直接复制，不作数值归一化或色彩转换。缩小后的层以刚得到的工作图像为源，再使用同一规则扩展。

### 4.4 整数金字塔怎样缩小

以下 `S(0,0)` 指工作图像原点，不是 padding 原点。

`rfilter=0` 直接平均相邻 `2×2`：

$$T(x,y)=D(S(2x,2y),S(2x+1,2y),S(2x+1,2y+1),S(2x,2y+1)).$$

整数只舍入一次。输入 `[0,0;0,1]` 得到 0；若先分别平均两行再平均，会因两次舍入错误地得到 1。

`rfilter=1` 先纵向、再横向。内部位置对偏移 `-1,0,1,2` 使用权重 `1,3,3,1`，除以 8 并舍入。纵向先生成宽 `2w`、高 `h` 的中间样本 `V`，它们已经舍入到样本精度；横向再对 `V` 滤波。目标首末行、首末列使用对应的二点平均。只有一行或一列时也走这个边界规则。

`rfilter=2` 同样先纵后横，中间结果同样先舍入。内部改用偏移 `-2,-1,0,1,2,3`，权重 `1,5,10,10,5,1`，除以 32；分组为 `R5(a+((f+10(c+d))+5(b+e)))`。边界仍用二点平均。这里全是正权重，不是后面亚像素插值的带负权重滤波器。

例如大图只有 `S(4,4)=10`，其余为零，整数 `rfilter=1` 的目标 `(2,2)` 先得到 `V(4,2)=R3(30)=4`，再得 `R3(12)=2`；`rfilter=2` 则先得 `R5(100)=3`，再得 `R5(30)=1`。float32 对应为 1.40625、0.9765625。

### 4.5 半像素相位

在带 padding 的整张平面上插值。对长度为 `m` 的一维序列 `z`，最后一个位置复制原样本；其他位置按下表计算：

| `sharp` | 内部公式 | 内部位置 |
| --- | --- | --- |
| 0 | `A(z(i),z(i+1))` | 所有 `i<m-1` |
| 1 | `K(R4(9(z(i)+z(i+1))-z(i-1)-z(i+2)))` | `1≤i<m-3` |
| 2 | `K(R5(z(i-2)+z(i+3)+20(z(i)+z(i+1))-5(z(i-1)+z(i+2))))` | `2≤i<m-4` |

不满足内部范围、又不是末点的位置使用二点平均。负系数使结果可能超出整数样本范围，所以在舍入后裁剪，不能在求和中途把负值去掉。各平面带 padding 的宽、高至少为 2、4、6，分别对应 `sharp=0,1,2`。

记水平操作为 `H`，垂直操作为 `V`。`sharp=0` 的双向半像素相位 `J` 用原图相邻四点一次平均；最后一列纵向二点平均，最后一行横向二点平均，右下角复制。`sharp=1/2` 则 `J=H(V(B))`，保留纵向步骤已经发生的舍入和裁剪。

`pel=2` 的四个相位为 `P00=B,P10=H(B),P01=V(B),P11=J`。

float32 的带符号滤波还保留运算分组：四点横向分子为 `-(a+d)+9(b+c)`，纵向为 `((-a)-d)+9(b+c)`；六点分子为 `a+(f+5(4(c+d)-(b+e)))`，之后分别除以 16、32。浮点不裁剪。

### 4.6 四分之一像素相位

`pel=4` 先把整数和半像素相位命名为 `P00,P20,P02,P22`。其余相位用二点平均生成；`+x/+y` 表示在对应相位中向右/下一个整数坐标：

| 相位 | 计算 | 定义范围，带 padding 尺寸为 `a,c` |
| --- | --- | --- |
| `P10` | `A(P00,P20)` | 全平面 |
| `P12` | `A(P02,P22)` | 全平面 |
| `P01` | `A(P00,P02)` | 全平面 |
| `P21` | `A(P20,P22)` | 全平面 |
| `P11` | `A(P01,P21)` | 全平面 |
| `P30` | `A(P00(+x),P20)` | `u<a-1` |
| `P32` | `A(P02(+x),P22)` | `u<a-1` |
| `P31` | `A(P01(+x),P21)` | `u<a-1` |
| `P03` | `A(P00(+y),P02)` | `v<c-1` |
| `P23` | `A(P20(+y),P22)` | `v<c-1` |
| `P13` | `A(P03,P23)` | `v<c-1` |
| `P33` | `A(P03(+x),P23)` | 两个限制都满足 |

每次平均分别舍入。需要右侧或下侧样本的相位在最右列、最下行可能没有定义；这些位置不是“再复制一下就行”的输出。后续分析必须保证所需候选的整个采样块避开未定义位置。

### 4.7 外部亚像素图像

有 `pelclip` 且 `pel>1` 时，对每个非零相位，从放大输入 `E` 中取：

$$P_{a_x,a_y}(x+h_p,y+v_p)=E(pel\,x+a_x,pel\,y+a_y).$$

先在实际图像区域取样，再把每个相位独立作最近边缘扩展，因此外部相位定义在完整工作和 padding 范围。整数相位仍来自原始 `clip`，`sharp` 不参与外部相位生成；粗层也继续由原始整数图像缩小。

`pelclip` 尺寸需为原图的 `pel` 倍，帧数相同，格式相同。`pel=1` 时只验证其固定尺寸与相同格式，不请求它的帧，也不要求其帧数和尺寸符合放大关系。

## 5. 一个完整的数值例子

取 GRAY8 原图 `4×4`，每行 `[10,14,18,22]`，块 4、重叠 0、padding 1、`onelevel=true,pel=2,sharp=0`。

工作尺寸仍为 `4×4`，带 padding 为 `6×6`，每行整数相位都是 `[10,10,14,18,22,22]`。各行相同，所以上下 padding 也不产生新数值。

在原图第一个样本对应的带 padding 坐标 `(1,1)`：整数相位为 10；水平半相位为 `(10+14)/2=12`；垂直半相位为 10；双向半相位为 `(10+14+10+14)/4=12`。于是该位置的四个相位是 `10,12,10,12`。

输出可见图像仍为原来的 `4×4`，附带工作尺寸 4、padding 1、pel 2、层数 1 等 Super 属性及上述辅助样本。

## 6. 参数与计算步骤对照

| 参数 | 默认与约束 | 作用 |
| --- | --- | --- |
| `clip` | 必需；固定尺寸/格式的受支持 GRAY/YUV，整数 8～16 位或 float32 | 原始样本和可见输出 |
| `blksize` | 必需；支持的块对见 [Analyse](analyse.md) | 工作覆盖、层数 |
| `overlap` | 必需；各轴 0 到半块，色度对齐 | 块步长 |
| `pad` | `[16,16]`；亮度两个值均正 | 平面扩展、缩小几何 |
| `onelevel` | false | 强制只保留第 0 层 |
| `rfilter` | 1；0～2 | 金字塔缩小滤波 |
| `sharp` | 2；0～2 | 内建半像素滤波 |
| `pel` | 2；1、2、4 | 第 0 层相位数量为 `pel²` |
| `pelclip` | 省略 | 替代非整数相位 |
| `prefix` | `MVUtensils` | Super 属性及辅助数据命名 |

轴参数一个值复制到两个轴，两个值分别对应 X/Y；超过两个值报错。若宿主传入显式空数组，`blksize/overlap/pad` 回退到 `8,8`、`0,0`、`16,16`；必需参数的省略仍是错误。

## 7. 边界、缺失数据与错误

图像不得小于块，尺寸、块和重叠须满足色度对齐。滤波会读取的区域必须确实存在，不能靠内存中碰巧有内容来补足。`pel=4` 的未定义边缘不因分配空间足够大而变成有效样本。

可见样本原样传递，Super 辅助数据在帧复制和并发读取后仍应保持有效。同 prefix 的旧 Super 数据被新结果替代，其他属性保留。输出只请求当前源帧，以及需要时的同编号 `pelclip` 帧。

## 8. 数值精度与结果确定性

两次二点平均不等于一次四点平均，纵横滤波的中间舍入不能省略。整数插值保留负中间值直到明确裁剪；浮点样本不限制在 `[0,1]`。每层和相位的逻辑样本由上述公式确定，与内部堆叠方式、行缓存及执行顺序无关。
