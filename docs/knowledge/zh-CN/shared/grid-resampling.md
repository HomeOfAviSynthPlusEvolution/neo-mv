# 块网格重采样：从每块一个数到每像素一个数

三种 mask 把小网格中的强度展开到画面；Flow 系列把小网格中的位移展开成稠密位移场。它们共用空间坐标映射，但整数和浮点的数值步骤不同。

## 1. 坐标按完整覆盖范围计算

当前目标平面的块参数为 `Bx,By,Ox,Oy`，网格为 `Nx,Ny`，完整覆盖为 `WB=Nx(Bx-Ox)+Ox,HB=Ny(By-Oy)+Oy`。可见尺寸不得超过覆盖。裁去右下部分不会把剩余网格重新拉伸。

对像素 x：

$$D_x=2W_B,\quad U_x=(2x+1)N_x-W_B,\quad i=\lfloor U_x/D_x\rfloor,\quad R_x=U_x-iD_x.$$

这对应连续网格坐标 `(x+0.5)Nx/WB-0.5`。Y 同理得到 j 和 Ry。四个邻格分别夹到网格边界，保留原始插值比例。这里扩展的是小网格，不是给 Super 的越界采样提供许可。

## 2. 整数：两轴各舍入一次

令 Q=16384，把精确有理数 `Q·Rx/Dx`、`Q·Ry/Dy` 按最近偶数舍入为 a、b。互补系数严格为 Q-a、Q-b，不单独舍入。

一维插值为：

$$L(s_0,s_1,k)=\left\lfloor\frac{(Q-k)s_0+ks_1+Q/2}{Q}\right\rfloor.$$

系数量化是最近偶数，样本舍入却是半值向正无穷，包括负位移。两者不能混用。

当 `2WB·Ny<HB·Nx+WB·HB` 时先水平再垂直，否则先垂直再水平，包括相等情形。第一轴的整数结果交给第二轴，不能延后到最后只舍入一次。判断使用完整覆盖，不使用裁剪后的尺寸。

例如 `2×2` 网格 `[[0,1],[0,3]]`，块 `3×3`，无重叠，输出 `6×6`。在 `(2,2)` 两轴比例均为 1/3，量化系数为 5461，先水平得 0、1，再垂直得 0；一次对真实二维值 5/9 舍入会得 1，因而不同。

## 3. 浮点：固定先横后纵

float32 网格用 binary64 比例 `a=Rx/Dx,b=Ry/Dy`，先算两行的 `(1-a)G左+aG右`，再算 `(1-b)h0+bh1`，每次 binary64 运算独立舍入，最终一次转换为 binary32。这里不使用 14 位量化系数，也不选择轴顺序，不作范围重映射。

## 4. 一个一维例子

网格 `[0,100]`、两块各宽 4、无重叠，输出宽 8，整数一行是 `[0,0,13,38,63,88,100,100]`。可见宽改成 6，只保留前六项。

float32 网格 `[0,1]` 在相同几何下为 `[0,0,0.125,0.375,0.625,0.875,1,1]`。有符号整数网格 `[0,4]` 则为 `[0,0,1,2,3,4,4,4]`。

网格值在输入前已由对应 mask 量化，不能先放大未量化得分再转整数。所有几何乘积用足够宽的精确整数，覆盖尺寸很大也不意味着必须分配同等大的中间图像。
