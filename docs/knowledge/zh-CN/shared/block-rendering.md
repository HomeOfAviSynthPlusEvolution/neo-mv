# 块渲染：采样坐标、重叠窗口与可见输出

[Compensate](../compensate.md) 为每块选一个图像来源；[Degrain](../degrain.md) 为每块生成多个时间样本的加权值。两者随后共用这里的块合成过程。

## 1. 图像与向量几何怎样对应

`clip` 和 Super 的实际尺寸、样本类型、位深、色彩族、色度比例及正帧数相同。输出帧率来自 clip，辅助节点不必同帧率。向量载体像素格式无关，但节点须能提供所需帧。

分析工作尺寸、实际尺寸、padding、pel 与 Super 一致。块网格覆盖必须满足 `Wr≤Nx(Bx-Ox)+Ox≤W`，垂直同理；不能少覆盖后再补黑。处理色度时块和重叠须按实际渲染比例对齐。分析精度可与渲染精度不同，阈值仍按分析精度计算。

当前向量元数据除正的 Levels 可变化外，其他有效标量须与创建时一致。完整损坏数据先报错，不能被时间越界掩盖。通过场景判断且 `n+d` 在序列内才有可用参考，不夹参考帧编号。公共状态见 [分析数据](analysis-data.md)，场景阈值见 [SCDetection](../sc-detection.md)。

## 2. 从向量到块采样坐标

亮度块起点为 `x,y`，位移 `dx,dy` 为亮度 pel 单位。渲染平面的比例为 `rx,ry`，先对总坐标向下取整：

$$a_x=\left\lfloor\frac{px+d_x}{r_x}\right\rfloor,\quad a_y=\left\lfloor\frac{py+d_y}{r_y}\right\rfloor.$$

再拆为 `qx=floor(ax/p),αx=ax-pqx`，Y 同理。从 Super 相位 `(αx,αy)` 的 `(hP+qx+i,vP+qy+j)` 读取块内样本。

例如 `p=2,x=0,dx=-1,rx=2`：`ax=-1,qx=-1,αx=1`，是向左半个色度像素。这里与 Analyse 先对色度运动分量向零取整的误差采样不同，不能共用错误的坐标换算。

整个生成块都须位于相位定义范围，最终被裁掉的区域也不例外。Degrain 在创建时验证整个公共向量域及中心位移；Compensate 验证时间缩放后的整个域和允许的当前场位移，实际带场位移的参考脚印还需逐帧检查。零权重或很差的 SAD 都不豁免几何验证。

## 3. 重叠窗口怎样生成

对当前平面的块长度 `B`、重叠 `O`，内部块的一维窗口为：

$$w_m(i)=\begin{cases}
\cos^2\frac{\pi(i-O+1/2)}{2O}&i<O\\
1&O\le i<B-O\\
\cos^2\frac{\pi(i-B+O+1/2)}{2O}&i\ge B-O.
\end{cases}$$

没有重叠时全为 1。第一个块的左肩改为 1，最后一个块的右肩改为 1；只有一个块时两条规则同时生效，全窗口为 1。这样外缘不会因为缺少相邻块而衰减。

角度使用 binary32 的 π、每次乘除独立舍入，cos 结果也转成 binary32 后再平方。两个轴先相乘，再量化：

$$W(i,j)=trunc(fl32(fl32(fl32(w_y(j)w_x(i))\,2048)+0.5)).$$

不能分别量化两个一维窗口。`B=4,O=1` 时内部轴约为 `[0.5,1,1,0.5]`；单轴肩部对应二维权重 1024，两轴肩部相交为 512。

## 4. 块怎样拼成图像

无重叠时复制唯一覆盖块的样本，右下只输出可见范围。有重叠时，对每个可见像素按块行序取贡献。整数样本：

$$a_k=\lfloor q_kW_k/64\rfloor,\quad
out=clip\left(\left\lfloor\frac{\sum a_k+16}{32}\right\rfloor,0,2^b-1\right).$$

先分别除以 64 取整，再求和并除以 32。不是除以实际窗口权重之和；固定总尺度为 2048，窗口量化的影响保留。

float32 从 `z=+0` 开始，按块行序累加 `fl32(fl32(qk·Wk)/64)`，每次加法舍入，最后 `fl32(z/32)`。不加 16，也不裁到 `[0,1]`。

例如两个权重均 1024，块值 10、21：整数贡献 160、336，输出 `floor((496+16)/32)=16`；浮点输出 15.5。Degrain 块内先发生的时间加权舍入在此之前已经完成，不能把两级运算合并成一次平均。

无重叠、块宽 8、三块、可见宽 18、工作宽 32 时，分别输出 8、8、2 列。工作区大于覆盖区不改变裁剪起点，未被网格覆盖但又不在可见范围的工作样本不输出。

## 5. 通用阈值尺度

分析块面积、色度参与情况和分析精度决定：

$$F=\left(\frac{B_xB_y}{64}\,C_f\right)\frac{2^{\min(16,b_a)}-1}{255},\quad
C_f=\begin{cases}1+2/(r_xr_y)&\text{分析含色度}\\1&\text{否则}\end{cases}.$$

非负参数 `z` 缩放为 `S(z)=trunc(fl64(fl64(fl64(z)F)+0.5))`，因子按式中顺序逐次 binary64 舍入。10 位无色度 `8×8` 分析的 `S(400)=1605`，即使渲染视频为 8 位，也不能改成 400。
