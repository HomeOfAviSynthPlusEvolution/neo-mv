# Depan 图像采样：坐标类别、插值与边缘

全局补偿和稳像以六系数映射 `X=tx+ux+vy,Y=ty+wx+hy` 从源图像取样。它们处理整数 GRAY/YUV 图像，不依赖 Super 相位。

## 1. 平面换算和坐标类别

Y/GRAY 使用原映射；444 色度相同。422 色度令 tx/=2、v/=2、w*=2，ty 不变；420 色度令 tx/=2、ty/=2，其余不变。420/422 色度 blur=floor(blur/2)，444 不变。

当前平面大小 W,H，先将有限 tx、ty 分别夹到 `±fl32(W+H+64)`，其他系数不夹。精确比较选择类别：

- T：u=h=1，v=w=0，即纯平移。
- Z：v=w=0，但不满足 T，即轴对齐缩放和平移。
- R：其他映射。

这些类别决定实际舍入和边缘规则，不能因为某个 R 很接近平移就改走 T。

## 2. 每个像素的坐标怎样计算

以下浮点操作均逐次 binary32 舍入。

T 最近邻：`i=x+floor(fl32(tx+0.5))`，`Y=fl32(ty+fl32(y))`，`j=floor(fl32(Y+0.5))`。T 插值：`i=x+floor(tx)`，fx 为 tx 的小数部分；j=floor(Y)，fy 为 Y 小数部分。三次插值的近边缘规则另用固定 `fyT=fl32(ty-fl32(floor(ty)))`。

Z 独立计算 `X=fl32(tx+fl32(u·fl32(x)))`、Y 同理。最近邻对 X+0.5、Y+0.5 向下取整，插值取 floor 和小数部分。

R 最近邻/双线性在每行从 `X0=fl32(tx+fl32(v·y)),Y0=fl32(ty+fl32(h·y))` 开始，每列递推 `X←fl32(X+u),Y←fl32(Y+w)`，不能改为一次乘法。最近邻用 `trunc(fl32(X+0.5))`，包括负数；双线性用 floor 和小数部分。

R 三次则独立计算 `X=fl32(fl32(tx+fl32(u·x))+fl32(v·y))`、`Y=fl32(fl32(ty+fl32(w·x))+fl32(h·y))`，不用行递推。

所以 T 在 X=-0.75 时最近邻取 -1，R 同坐标却取 0。有限图外坐标交给边缘处理；非有限坐标是错误，不能当边框颜色。

## 3. 镜像和水平填充

mirror 位：上1、下2、左4、右8。普通单次镜像先对 q<0 且低边开启时令 q=-q，再对结果 q≥D 且高边开启时令 q=2D-q-2。每个条件只做一次，结果仍可能越界，不是周期反射。

通用双轴镜像分别处理 X/Y，若仍越界则返回边框动作 B。R 类的边缘使用这条规则，不使用水平 blur。

T/Z 对有效行使用专门水平填充，令 `C(k)=clip(k,0,W-1)`：

- 左侧 i<0 且左位开启：blur=0 取 P(C(-i),j)；否则 `ell=min(blur,-i)`，平均 k 从 `-i-ell+1` 到 `-i` 的 P(C(k),j)，整数向下取整。
- 右侧位开启且 i≥阈值 R：令 q=2W-i-2；blur=0 取 P(C(q),j)；否则 `ell=min(blur,i-W+δ)`，平均 k=q…q+ell-1。

普通填充使用 R=W、δ=1；双线性内部行填充使用 R=W-1、δ=2。每个列索引独立夹取，不因重复边缘样本缩短除数。禁用相应边就返回 B。“单样本填充”强制 blur=0。

例如 `[0,10,20,30,40]`，i=-2、左镜像开启，blur=0 得20，blur=2 得15。i=5、右镜像开启、blur=2，普通规则得到30，双线性规则得到35。

## 4. 最近邻 subpixel=0

T/Z 先对整数 j 作一次垂直镜像，行合法时直接取合法列，否则水平填充；行仍非法返回 B。R 先尝试原坐标，越界时通用双轴镜像，取单样本或 B，不进行 blur。

## 5. 双线性 subpixel=1

小数先量化为 `ax=floor(fl32(32fx)),ay=floor(fl32(32fy))`，范围含 32。系数分别 `[32-ax,ax]`、`[32-ay,ay]`。完整 `2×2` 内：

$$Q=\left\lfloor\frac{\sum_{e,f=0}^1c_x[e]c_y[f]P(i+e,j+f)}{1024}\right\rfloor.$$

无舍入偏置，零系数也不允许缺失相应采样位置。

T/Z 先算小数，再镜像 j，保留原小数。若 `0≤j<H-1`，完整列范围内用 Q，其他列使用双线性水平填充；j=H-1 时合法列直接复制，非法列 T 用单样本填充，Z 返回 B。其他行返回 B。

R 只有原坐标拥有完整 `2×2` 才插值，否则双轴镜像后只取单样本或 B，不重新尝试双线性。

单位 T、mirror=0 时，非底行最后一列因缺少右样本而返回 B；底行最后一列则直接复制。因此单位映射不普遍等于复制图像。

## 6. 三次 subpixel=2

`ax=trunc(fl32(256fx))`，Y 同理。a∈[0,256] 的四个整数系数为：

$$c_0=trunc\frac{-a(256-a)^2}{8192},\quad c_1=trunc\frac{256^3-512a^2+a^3}{8192},$$
$$c_2=trunc\frac{a(256^2+256a-a^2)}{8192},\quad c_3=trunc\frac{-a^2(256-a)}{8192}.$$

完整脚印要求 `1≤i<W-2,1≤j<H-2`，取 `P(i+e-1,j+f-1)`。T 先逐项量化 `kef=trunc(cx[e]cy[f]/2048)`，再算：

$$Q_T=clip\left(\left\lfloor\frac{\sum k_{ef}P+1024}{2048}\right\rfloor,0,M\right).$$

Z/R 不量化二维系数，算 `QZR=clip(floor(ΣcxcyP/2^22),0,M)`，没有偏置。系数有负数，累加用宽有符号整数，不重新归一化。

### 近边缘二次取样

指定的近边缘行使用未按 1/32 量化的 fx、fy。T 用固定 fyT，Z 用当前 Y 小数。只有下式标记项用 binary32，其余逐次 binary64：

$$B_2=trunc\left((1-f_y)((1-f_x)P_{00}+fl32(f_xP_{10}))+f_y((1-f_x)P_{01}+fl32(f_xP_{11}))\right).$$

T 直接存 B2，Z 再夹到样本范围。这不是 subpixel=1 的量化双线性。

### 三次边缘分派

T/Z 先算小数，再单次垂直镜像 j：

| 行 | 列 | 结果 |
| --- | --- | --- |
| `1≤j<H-2` | `1≤i<W-2` | T 用 QT，Z 用 QZR |
| 同上 | 合法边列 0、W-2、W-1 | P(i,j) |
| 同上 | 其他列 | 普通水平填充，可 blur |
| `j=0` 或 `H-2` | `0≤i<W-1` | B2 |
| 同上 | i=W-1 | P(i,j) |
| 同上 | 其他列 | 单样本水平填充 |
| j=H-1 | 合法列，T | P(i,j) |
| j=H-1 | 合法列，Z | floor((P(i,j)+P(i,j-1))/2) |
| j=H-1 | 其他列 | 单样本水平填充 |
| 其他行 | 任意 | B |

R 仅原坐标完整 `4×4` 时用 QZR，否则通用双轴镜像后单样本或 B，无 B2、底行平均或 blur。

高度 2、3 时没有三次内部行，但上述边缘仍有定义；宽度 1 也支持，合法的最后列走直接复制，不读不存在的邻列。模式2要求各实际平面 H≥2。

## 7. 边框动作与数值例子

DepanCompensate 的 B 是 Y/GRAY=0、U/V=`2^(b-1)`，不受范围标签影响。DepanStabilise 的后续叠层允许 B 表示保留已有目标像素，详见该函数。

双线性 `2×2` 值 `[0,10;20,31]`、fx=fy=0.5，结果15。三次半相位系数为 `[-256,1280,1280,-256]`，单个中心系数位置样本100、其余零时，T 与 Z/R 都得39。

Z 在底行值21、上行10时，三次边缘结果15，与 fy 无关；T 在同样底行直接取21。这些差异来自明确的类别与边缘分支，不应以“统一插值”替代。
