# DepanEstimate：从周期相关峰计算全局运动

## 1. 这个函数计算什么

`DepanEstimate` 比较当前帧与前一帧的第一平面，在一个或两个矩形窗口中寻找周期相关峰，输出水平位移、垂直位移、缩放和运动有效标志。它不估计旋转，所以 `Depan_rot` 总是零。

默认输出图像逐样本复制当前帧。计算结果放在 [Depan 运动属性](shared/global-motion.md)中；`show` 可以把相关曲面画进第一平面，`info` 可以把结果叠成文字。

## 2. 计算对象与记号

图像大小为 $W\times H$，共 $F$ 帧。一次基本观察 $j$ 比较当前图像 $A=clip[j]$ 与前一图像 $B=clip[\max(0,j-1)]$。窗口大小为 $w_x\times w_y$，面积 $K=w_xw_y$，搜索半径为 $m_x,m_y$。

相关曲面记作 $C(i,j)$。其下标是窗口内部的周期位移：横向下标 $w_x-1$ 对应位移 −1，而不是向右移动接近一个窗口宽度。

除整数下标与明确说明的计数外，下面的实数计算均使用 binary32；每一步运算都会舍入。输入整数样本保持原始数值尺度，例如 16 位样本不会先归一化到 0～1。

## 3. 总体计算流程

1. 确定窗口位置、尺寸和峰值搜索范围。
2. 为当前观察及其实际存在的前后相邻观察计算相关曲面。
3. 按固定顺序搜索峰值，计算置信度。
4. 对通过置信度检查的窗口做亚像素峰值拟合与场修正。
5. 合并一个或两个窗口的结果，再执行相邻观察的置信度检查。
6. 复制当前图像，写入运动属性，按需显示曲面和文字。

## 4. 逐步计算

### 4.1 窗口怎样确定

先令 $L=\max(wleft,0)$。`winx` 必须为非负偶数，且不超过 $W-L$。零表示选择不超过 $\min(W-L,8192)$ 的最大二次幂；结果至少为 2。显式宽度不受 8192 自动选择上限限制。

`zoommax=1` 使用一个窗口。其他值使用两个窗口，此时把上述宽度除以 2，结果仍须为正偶数。因此双窗口的原始宽度必须能被 4 整除。

当 `wleft<0` 时，单窗口起点是 $\lfloor(W-w_x)/2\rfloor$，双窗口左起点是 $\lfloor(W-2w_x)/4\rfloor$。否则直接使用 `wleft`。第二窗口起点为

$$left_2=left+\lfloor W/2\rfloor.$$

两个窗口都必须完全落在第一平面内；第二个窗口不一定紧接第一个窗口。

纵向令 $T=\max(wtop,0)$，要求 $0\le winy\le H-T$。`winy=0` 选择不超过 $\min(H-T,8192)$ 的最大二次幂；显式奇数高度可以使用。`wtop<0` 时上下居中，否则使用指定起点。

负的 `dxmax/dymax` 分别得到 $\lfloor w_x/4\rfloor,\lfloor w_y/4\rfloor$。最终必须满足

$$0\le m_x<\lfloor w_x/2\rfloor,\qquad0\le m_y<\lfloor w_y/2\rfloor.$$

因此高度 1 无效，零搜索半径则有效。`fields` 和 `pixaspect` 都不改变窗口尺寸或取样行。

例如 1920×1080 的默认单窗口为 1024×1024，起点 $448,28$，搜索半径 $256,256$。开启双窗口后，每个窗口为 512×1024，横向起点 224 和 1184，横向搜索半径 128。

### 4.2 周期相关到底在计算什么

对两个窗口分别做负指数的实数正向 FFT，形成

$$\widehat H=\overline{\widehat A}\,\widehat B.$$

若两复数分别为 $a_r+ia_i,b_r+ib_i$，乘积为

$$h_r=\operatorname{fl32}(\operatorname{fl32}(a_rb_r)+\operatorname{fl32}(a_ib_i)),\quad
h_i=\operatorname{fl32}(\operatorname{fl32}(a_rb_i)-\operatorname{fl32}(a_ib_r)).$$

再执行不归一化的正指数逆 FFT。其理想数学结果是

$$C(i,j)=K\sum_{y=0}^{w_y-1}\sum_{x=0}^{w_x-1}A(x,y)B((x+i)\bmod w_x,(y+j)\bmod w_y).$$

这可以理解为：把前一帧的窗口周期平移，逐位置乘上当前窗口，再把所有乘积加起来。数值大的位置表示两窗口在该平移下有较强的一致性。正位移表示当前样本对应前一图像右方或下方的样本。

这里没有减均值、窗函数、零填充或按位深缩放。面积因子 $K$ 也不能省略：后面的置信度包含常数 0.1，整体缩放会改变置信度。

实数窗口的半谱尺寸是 $w_y\times(w_x/2+1)$，未保存的另一半由共轭对称关系确定。不能把整条首列或末列频谱的虚部抹掉；只有完全自共轭的位置必须为实数。

### 4.3 峰值的搜索顺序与置信度

依次访问行 `0…my, wy-my…wy-1`，每行访问列 `0…mx, wx-mx…wx-1`。半径零时第二段为空。窗口中间不属于候选区域。

最大值从 $C(0,0)$ 开始，仅在新值严格较大时更换，所以相等峰值保留先访问的位置。同时按访问顺序用 binary32 累加全部候选值。候选数 $J=(2m_x+1)(2m_y+1)$。令

$$P=C_{max}/K,\qquad M=(\mathrm{sum}/J)/K.$$

峰下标小于半宽时直接作正位移，否则减去宽度；纵向同理。这里比较使用精确整数 $2i<w_x$。

基本峰值置信度及位移惩罚为

$$T_0=((P-M)100)/(P+0.1),$$
$$A_x=m_x+1,\quad A_y=m_y+1,\quad d_x=A_x+stab|dx|,\quad d_y=A_y+stab|dy|,$$
$$T=T_0\left(\left((A_x/d_x)A_y\right)/d_y\right).$$

峰越突出，$P-M$ 越大；`stab` 为正时，大位移还会降低置信度。置信度没有被裁到 0～100；负的有限 `stab` 可以提高它，也可能令分母变成零而报错。

仅当 $T\ge trust$ 时窗口有效。无效窗口的亚像素位移直接为零，但保留 $T$，也不执行以下拟合。

### 4.4 亚像素修正

取峰值 $c_0$ 以及横向周期相邻值 $c_-,c_+$，计算

$$f_1=(c_+-c_-)/2,\qquad f_2=(c_++c_-)-2c_0,$$
$$a_x=\begin{cases}0&f_2=0,\\\min(1,\max(-1,-f_1/f_2))&f_2\ne0.\end{cases}$$

如果 $|dx+a_x|>m_x$，把修正量 $a_x$ 整个置零。它不会把结果截在边界上。纵向使用上下周期邻点得到 $a_y$。这些邻点可以在峰值搜索区域之外。

普通帧输出 $dx'=dx+a_x,dy'=(dy+a_y)/pixaspect$。场模式先把 $a_y$ 加上顶场的 0.5 或底场的 −0.5，再乘 2，整数 $dy$ 也乘 2，最后除以 `pixaspect`。修正后不再检查 `dymax`。

例如左右邻值为 6、8，峰值为 10，则 $a_x\approx1/6$。整数峰在 0 时保留修正；整数峰已经等于正搜索边界时舍弃修正。

### 4.5 双窗口与相邻观察检查

单窗口直接提供位移、置信度和有效性，缩放为 1。双窗口令 $D=left_2-left$，先计算

$$z_*=1+(dx'_2-dx'_1)/D.$$

只有两个窗口均有效且 $|z_*-1|<zoommax-1$ 时才接受。位移取两个窗口的算术平均，缩放取 $z_*$。不接受时位移置零、缩放置 1。两种结果都保留 $T=\min(T_1,T_2)$，相等时保留第一项。纵向位移的分歧不用于估计旋转。`zoommax<1` 仍然启用双窗口，但永远不能通过这个严格比较。

第 0 个基本观察强制无效、置信度为零，但此前的相关运算、样本检查和场序检查仍执行。

对于请求帧 $n$，还需要基本观察 $n-1,n+1$ 中实际存在的那些。若

$$T_n<2\,trust\quad\text{且}\quad T_n<0.5T_{neighbor},$$

任意一个邻观察满足条件，就把当前结果判为无效。两个比较都严格小于；邻观察自身是否有效不影响其置信度参与比较。使用的是邻观察的基本置信度，因而不会递归依赖邻帧的最终输出。

最终无效运动固定输出 $(dx,dy,rot,zoom,good)=(0,0,0,1,0)$。有效运动保留位移与缩放，旋转为零。请求 $n$ 最多使用图像 $n-2…n+1$，按片段边界裁剪；即使当前已经无效，所需邻观察仍须计算。

### 4.6 曲面显示与文字

`show=true` 对当前观察的每个完整曲面独立求最小值和最大值，计算

$$q=(C-C_{min})\left(M_{pixel}/(C_{max}-C_{min})\right).$$

整数图像的 $M_{pixel}=2^b-1$，浮点图像为 1。整数结果向零截断，并检查截断后的整数是否在合法范围；浮点结果直接保存。常量曲面因分母为零而报错。显示位置就是原分析窗口的位置，不把零位移移到矩形中心，也不裁成搜索区域。双窗口分别归一化，色度及矩形以外的像素保留原值。

`info=true` 写入 `DepanEstimate_info`，格式例如 `fn=2 dx=1.00 dy=0.00 zoom=1.00000 trust=88.01 bad=0`。无效运动显示重置后的位移，却仍显示当前基本置信度。随后调用宿主文字渲染器；在 VapourSynth 中是只选择该属性的 `text.FrameProps`。文字绘制在曲面显示之后。

## 5. 一个完整的数值例子

使用三帧 4×4 GRAY8 图像，每帧只有一个值为 1 的点，其余为零。三帧亮点坐标依次为 $2,0$、$1,0$、$0,0$。设窗口 4×4，搜索半径均为 1，`stab=0,trust=4,zoommax=1`。

观察 1 中，当前亮点在 $1,0$，前一帧亮点在 $2,0$。因此理想曲面仅 $C(1,0)=16$，其他位置为零。候选数 9，得到

$$P=1,\quad M\approx1/9,\quad T\approx((1-1/9)100)/1.1\approx80.80808.$$

峰的左右与上下邻值相同，所以亚像素修正为零，位移为 $1,0$。观察 2 得到相同结果。观察 0 强制置信度零、运动无效；它不会使观察 1 的正置信度遭拒。观察 1、2 的置信度都大于 8，也不会触发相邻检查。

最终第 0 帧输出无效运动，第 1、2 帧输出 `(1,0,0,1,1)`。在 `show=false,info=false` 时三幅图像均保持原始像素。实际 FFT 在上述理想值附近产生其 binary32 结果。

## 6. 参数与计算步骤对照

| 参数 | 默认值 | 进入哪一步 |
| --- | --- | --- |
| `clip` | 必填 | 提供第一平面的窗口与输出图像 |
| `trust` | 4 | 局部接受门槛与邻观察检查，范围 0～100 |
| `winx,winy` | 0,0 | 窗口尺寸；零自动选择 |
| `wleft,wtop` | −1,−1 | 窗口起点；负值自动放置 |
| `dxmax,dymax` | −1,−1 | 周期峰值搜索半径；负值自动选择 |
| `zoommax` | 1 | 决定单/双窗口与严格缩放检查 |
| `stab` | 1 | 对整数峰位移施加置信度惩罚 |
| `pixaspect` | 1 | 亚像素位移的纵向除数，必须为正 |
| `fields,tff` | false,省略 | 场修正及可选场序覆盖 |
| `show,info` | false,false | 曲面显示与文字显示 |

## 7. 边界、缺失数据与错误

支持固定尺寸 GRAY/YUV 的整数 8～16 位和 float32；不支持 RGB。只分析第一平面，因此色度子采样本身不影响估计。窗口内整数必须在声明位深范围内，浮点样本必须有限；窗口外的样本不参与这些检查。

`fields=true` 时，每个所需基本观察的当前图像都要提供有效场序，或由 `tff` 按帧号交替确定。只作为前一图像使用的帧不另行要求场序。无效运动不能掩盖缺属性、非法像素或 FFT 错误。

输出覆盖五个 Depan 运动属性，并删除 `DepanEstimateFFT`、`DepanEstimateFFT2`、`DepanEstimateX`、`DepanEstimateY`、`DepanEstimateZoom`、`DepanEstimateGood`、`DepanEstimateTrust`。这些旧属性不作为计算输入。其他属性继承；`info=false` 也保留已有同名诊断属性。

## 8. 数值精度与结果确定性

FFT 使用单精度 PocketFFT 配置，正逆变换都不归一化。不能用双精度 FFT 后再转 float32 来替代该计算。固定构建与执行配置对相同输入给出可重复结果；不同优化 FFT 配置可能有通常的浮点差异，而峰值比较、置信度门槛会把微小差异转为离散决定。可以用 [KernelInfo](kernel-info.md) 查看实际执行配置。

所需 FFT 输出、相关值及后续算术都必须有限，零分母是错误。峰值并列顺序、逐项累加顺序和严格/非严格比较均影响结果。诊断小数采用最近偶数舍入，保留负零，最多保存 127 字节；最终文字像素还取决于宿主文字渲染器。
