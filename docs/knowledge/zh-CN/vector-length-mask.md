# VectorLengthMask：把运动长度转换为灰度

## 1. 这个函数计算什么

每个块的向量长度经过尺度归一化、幂变换和量化，得到一个灰度值，再扩展为逐像素 mask。SAD 只影响前面的场景可用性，不参与长度公式。

## 2. 计算对象与记号

向量 `(vx,vy)` 的单位为 pel，`p` 为每像素的向量单位。`M` 为整数输出最大值或浮点的 1。共享常量 `f=fl32(1/ml)`，gamma 为 binary32。

## 3. 总体计算流程

按 [共同输入规则](shared/mask-input.md) 建立输出，判定当前分析场是否可用；不可用则填 scval，可用则计算长度网格并 [重采样](shared/grid-resampling.md)。

## 4. 逐步计算

创建时计算 binary32 的 `f2=f·f`、`g2=gamma/2`。每块先转为亮度像素位移：

$$d_x=fl64(v_x/p),\quad d_y=fl64(v_y/p),\quad q=fl64(fl64(d_xd_x)+fl64(d_yd_y)).$$

然后 `a=fl64(q·fl64(f2))`，`L=fl64(M·pow64(a,fl64(g2)))`，块输出为 Q(L)。数学上对应 `M·(长度/ml)^gamma`，实际计算保留 f2 和 g2 的 binary32 舍入，不能随意改写成先开平方。

长度不包含块起点和 padding，delta 的正负也不影响它。time 参数虽然验证，完全不进入这个计算。

## 5. 一个完整的数值例子

有效 GRAY8 单块 `8×8` 分析，p=1，向量 `(4,0)`、SAD=0，ml=8、gamma=2。`f=1/8,f2=1/64,g2=1`，`q=16,a=0.25,L=63.75`。整数截断得到 63，单块网格展开后整幅都是 63。

相同参数使用 float32 分析输出得到 0.25；10 位输出得到 `trunc(1023/4)=255`。输出精度取自分析数据，不是向量载体的像素格式。

## 6. 参数与计算步骤对照

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `vectors` | 必需 | 分析字段，载体像素忽略 |
| `ml` | 100.0，有限正数 | 长度归一化 |
| `gamma` | 1.0，有限非负 | 长度得分幂变换 |
| `time` | 100.0，有限 0～100 | 仅验证，无计算作用 |
| `scval` | 0.0，有限 | 不可用场填充值 |
| `thscd1,thscd2` | 400、51.0 | 场景可用性 |
| `prefix` | `MVUtensils` | 分析属性名称 |

## 7. 边界、缺失数据与错误

零向量在 gamma>0 时得到零；gamma=0 时包括零向量在内都得到 M。但不可用场仍填 scval。非有限中间值报错，不能把溢出简单裁为最大灰度。其余输入和属性规则见 [共同说明](shared/mask-input.md)。

## 8. 数值精度与结果确定性

先量化每块再放大。整数得分截断、放大插值舍入和 scval 舍入分别遵循不同规则。输出只含 `_Range=[1]`。
