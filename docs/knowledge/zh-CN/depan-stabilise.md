# DepanStabilise：把累计运动变成平滑采样路径

## 1. 这个函数计算什么

`DepanStabilise` 读取相邻帧的全局运动，把它们累积成一条路径，再计算平滑路径与实际路径之间的修正映射。输出图像按这个映射重采样，并可由前后帧图层填入当前采样无法覆盖的位置。

`method=0` 使用带预测和校正的惯性递推；`method=1` 使用对称时间窗口加权平均。两个方法的边界、缩放和限制处理不同。

输出尺寸、格式、帧数和帧率不变。输入 `data` 只提供 [Depan 运动属性](shared/global-motion.md)，其像素不参与运算。函数不导出新的修正运动属性。

## 2. 计算对象与记号

当前帧号为 $n$，共 $F$ 帧。$m_j$ 描述帧 $j$ 与前一帧之间的运动。区间 $[b,h]$ 的首帧作为累计基准；$C_j$ 是实际累计路径，$S_j$ 是平滑路径，$Q$ 是最终输出到输入的采样映射。

映射统一写为

$$X=t_x+ux+vy,\qquad Y=t_y+wx+hy.$$

因此修正横移 +2 表示输出位置从源图右方两像素读取。用户 `initzoom` 对应的初始采样比例是倒数 $z_0=1/initzoom$。

## 3. 总体计算流程

1. 从帧率、截止参数、缩放和限制参数计算系数与时间权重。
2. 检查运动有效性，确定本帧的累计区间。
3. 累积相邻运动，得到各帧路径映射。
4. 计算惯性或窗口平滑路径，得到当前修正；惯性方法再作片尾渐变与限制。
5. 根据修正映射选择前、后图像及其采样映射。
6. 依次渲染前图层、后图层、当前图层，继承当前帧属性，按需显示诊断文字。

## 4. 逐步计算

### 4.1 参数与有效区间

完整系数公式见 [稳像的时间平滑与修正限制](shared/stabilisation-smoothing.md)。有效像素纵横比为 `pixaspect/(fields?2:1)`；这里的 `fields` 仅影响几何比例，不读取 `_Field`，也没有 `tff`。

索引 0 的运动始终采用合成的无效元组 `(0,0,0,1,0)`，不读取 `data[0]` 的运动属性。其他被访问的位置须完整解码五个属性，即使有效标志为假，也不能缺字段或含非法数值。

方法 0 先计算 $t=(10fps)/cutoff$。若不满足 $t<5fps$，改用 $5fps$；这一处初始 $t$ 可以溢出为正无穷，但上限必须有限。令

$$b_0=\max(0,\operatorname{trunc}(\operatorname{fl32}(n)-t)),\quad h=n.$$

从 $n$ 向前检查到 $b_0$，遇到首个无效运动就在该位置设 $b$ 并停止；否则 $b=b_0$。例如 25 fps、`cutoff=1,n=140`，先得到 $b_0=15$；若最近无效运动在 120，则从 120 开始累计，不再检查 119 的属性。

如果 $b=n$，当前映射直接取 $Q=Z(z_0)$，跳过平滑、片尾渐变和限制。后续选层、采样和诊断仍执行。

方法 1 先取 $b_0=\max(0,n-r),h_0=\min(F-1,n+r)$。向前扫描得到 $b_1$；另从 $n+1$ 向后扫描，首个无效位置 $j$ 令 $h_1=\max(j-1,n)$，无无效值则 $h_1=h_0$。即使当前运动无效，向后的扫描也要执行。然后对称缩短：

$$k=\min(n-b_1,h_1-n),\qquad b=n-k,\quad h=n+k.$$

已访问但最后被对称裁掉的数据仍必须合法。即使最后只有 $[n,n]$，也执行窗口计算和映射往返转换。

### 4.2 从相邻运动到当前修正

令 $M$ 把一个运动转为采样映射，从 $C_b=I$ 开始逐段复合 $C_j=M(m_j)\circ C_{j-1}$。基准帧本身的运动不加入，因此区间可以从一个无效运动位置开始。

方法 0 的未缩放路径前两个位置都初始化为恒等映射，后面每次对平移与旋转分量作一次预测、一次校正，对缩放对角项作递推平均。可选自适应缩放在未缩放路径算完后独立处理。

方法 1 对平移与旋转分量作余弦权重平均，对角分量只取当前帧前后一格。可选缩放也使用独立权重窗口。两种方法得到 $S$ 后，都从

$$Q=S\circ Inv(C_n)$$

得到实际路径到平滑路径的修正。这里 $Inv$ 是相似运动模型下的特定逆，不能任意替换为通用仿射逆。其公式、逐步递推及自适应缩放全部在 [平滑计算详解](shared/stabilisation-smoothing.md)中展开。

方法 0 接着转回运动，进行片尾渐变及按 dx、dy、缩放、旋转排序的限制，再转回映射。限制可能缩小某个分量，也可能重置整个修正并设 $b=n$。方法 1 不做这些限制，但同样必须完成一次映射→运动→映射转换。

### 4.3 选层与重采样

前后图层分别从 $Q$ 开始，根据各候选映射的平移量和时间距离评分，严格改善才更换图像。最终搭配的是搜索结束时的映射。后向搜索先完整解码范围内的全部运动，再根据有效性决定在哪里停止。

随后按前、后、当前的顺序覆盖像素。邻层用最近邻，当前层用 `subpixel`。第一层可以反射边缘并写背景；后续层的背景分支保留前层像素。完整搜索公式与覆盖例子见 [邻帧选择与逐层覆盖](shared/stabilisation-layers.md)，插值公式见 [Depan 采样](shared/depan-sampling.md)。

即使最终映射为恒等，也不直接返回原图：插值边界规则及已有邻层仍可能改变边缘像素。

### 4.4 输出与诊断

属性全部继承 `clip[n]`，包括原来的五个 Depan 运动属性。它们不会被修正运动覆盖。

`info=true` 时，使用完整分辨率、尚未做分平面转换或平移限制的最终 $Q$，再次转成运动，生成 `DepanStabilise_info`：

```text
frame=4 base =0 dx=2.00 dy=0.00 rot=-0.000 zoom=1.00000
```

若 $b=n$，使用 `frame=4 BASE!=4` 形式。位移保留两位、旋转三位、缩放五位小数，最近偶数舍入并保留负零，最多保存 127 字节。然后让宿主文字渲染器只渲染该属性。邻层映射不进入诊断；`info=false` 保留已有同名属性。

## 5. 一个完整的数值例子

取 48×48 图像，帧率 24，`cutoff=3,method=1,initzoom=1,addzoom=false`，像素纵横比为 1，`prev=next=0,subpixel=0`。请求第 1 帧，片段至少有三帧。运动 1 为横移 +1，运动 2 为横移 0，二者有效。

时间半径 $r=24/(4\times3)=2$。向前扫描到合成无效运动 0，向后受三帧片段边界限制；对称区间最终为 $[0,2]$。累计横移为 `[0,1,1]`，对角项均为 1，其他分量为零。

记 $c=w(1)\approx0.70710677$，三帧权重为 `[c,1,c]`。平滑横移为

$$t_{x,S}=(0c+1+1c)/((c+1)+c)\approx0.70710677.$$

当前累计横移为 1，所以原始修正约为 −0.29289323。运动往返转换后仍按所得映射采样。最近邻横坐标为 $x+\lfloor t_x+0.5\rfloor=x$，纵向不变，所以这个例子的像素取自当前帧同一位置。

改用双线性时，同一个小数修正会参与插值；这说明“当前最近邻像素没有改变”不等于修正计算没有产生位移。

## 6. 参数与计算步骤对照

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `clip,data` | 必填 | 原图与相邻全局运动 |
| `cutoff` | 1 | 正数；时间半径、回看长度与惯性响应 |
| `damping` | 0.9 | 惯性阻尼，有限负值也允许 |
| `initzoom` | 1 | 正数；倒数作为初始采样比例 |
| `addzoom` | false | 启用对应方法的自适应缩放 |
| `prev,next` | 0,0 | 非负；前后图层搜索范围 |
| `mirror,blur` | 0,0 | 首层反射位标记 0～15；非负横向边缘平均范围 |
| `dxmax,dymax` | 60,30 | 惯性非线性系数及修正限制 |
| `zoommax,rotmax` | 1.05,1 | 惯性缩放与旋转限制；负值可触发整体重置 |
| `subpixel` | 2 | 当前层最近邻 0、双线性 1、双三次 2 |
| `pixaspect,fields` | 1,false | 正纵横比；场模式把有效比例除以 2 |
| `fitlast` | 0 | 正数时在片尾逐渐回到初始修正 |
| `tzoom` | 3 | 非负；缩放时间系数与窗口半径 |
| `method` | 0 | 惯性 0、对称窗口 1 |
| `info` | false | 生成并渲染诊断文字 |

方法 1 仍检查全部参数类型、公开取值域与共用归一化，但不使用惯性系数、修正限制或 `fitlast`。

## 7. 边界、缺失数据与错误

输入图像支持固定格式整数 8～16 位 GRAY、YUV420/422/444，需要已知正帧率。双三次要求每个平面高至少 2；宽 1 可以。`data` 至少有 $F$ 帧，尺寸、格式、帧率不必相同。

运动属性的访问范围由区间扫描和选层决定；不能用未访问的坏属性使本帧失败，也不能跳过已访问的坏属性。无效运动表示区间边界，畸形属性表示错误，两者不同。

`tzoom=0` 可通过创建检查，但方法 1 自适应缩放的归一化分母为零；方法 0 则在实际需要缩放递推倒数时失败。大帧号转 float32 也可能使回看下界大于当前帧，此时报错而非静默修正下界。

惯性数值溢出在规定范围内可以恢复为初始修正，详见 [恢复规则](shared/stabilisation-smoothing.md)。其他非法算术、缺帧、分配失败或文字渲染失败不会自动变成原图输出。

## 8. 数值精度与结果确定性

所有路径和递推使用逐步 binary32 舍入。复合映射的两个对角系数可能略有不同；求逆、窗口平均和最终运动往返各有自己的处理方式，不能在中途强行对称化。

每个输出从自己的输入区间重新定义计算。请求顺序、重复请求和其他实例不会给递推提供隐藏的历史状态；一次恢复也不影响之后请求。固定执行环境中的计算可重复，文字叠加像素还由宿主渲染器决定。
