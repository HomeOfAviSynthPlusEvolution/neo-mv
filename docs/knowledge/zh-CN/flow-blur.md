# FlowBlur：在当前图像上沿两条运动轨迹取平均

## 1. 这个函数计算什么

`FlowBlur` 将两个方向的块向量展开为稠密轨迹，在当前 Super 图像中沿轨迹多次采样后平均。所有样本来自同一张图像，不是把多帧像素按时间平均。

## 2. 计算对象与记号

向量对 `[bw,fw]` 距离为 d>0。输出 n 使用 `B=bw[n-d]`、`F=fw[n+d]`，并非两者的第 n 帧。blur 先转 binary32，系数 `t=trunc(fl32(fl32(blur·256)/200))`。prec 为正 int32 有效值。

## 3. 总体计算流程

先检查两字段索引；边界越界则复制 clip。范围内验证两字段，任一不可用则复制 clip；可用时只读 Super[n]，生成稠密场、轨迹和完整采样列表，预检后按固定顺序平均。

## 4. 逐步计算

使用 [Flow 的稠密场生成](flow.md)，但场位移固定为零。没有遮挡 mask 和 ml。

当前平面像素中心 pel 坐标 q=(px,py)，对 F、B 两个稠密向量 G 各自计算：

$$z_G=tG,\quad a_G=\max(|z_{Gx}|,|z_{Gy}|),\quad
m_G=\left\lfloor\frac{trunc(a_G/prec)}{256}\right\rfloor.$$

m=0 不增加样本；否则先取整步进 `eG=trunc(zG/mG)`，然后对 i=1…m：

$$q_{G,i}=q+(\lfloor i e_{Gx}/256\rfloor,\lfloor i e_{Gy}/256\rfloor).$$

完整顺序是中心、F 方向升序、B 方向升序。重复坐标也重复计数。先截断步进再乘 i，不能改为直接按 `i·z/m` 分割整条线段。

把每个坐标拆成相位和整数位置，全部采样 Super[n]。若总数 c=1，精确复制中心存储位；c>1 的整数输出为 `floor(sum/c)`，不加舍入偏置。浮点以 binary64 累加，先中心后所有 F 再所有 B，每次加法舍入，最后除以 c 并转 binary32。

## 5. 一个完整的数值例子

内部帧 n、p=1、blur=200、prec=1，稠密 F=(2,0)、B=(-2,0)。t=256，每方向 m=2，采样水平偏移为 `[0,1,2,-1,-2]`。

若对应当前 Super 样本依次是 `[10,20,30,0,1]`，总和 61，整数结果 `floor(61/5)=12`，浮点结果为 binary32 的 12.2。属性来自 clip[n]。

把 blur 改为 50 得 t=64，两方向 m=0，只复制 Super 中心。不是复制 clip，除非字段不可用或索引越界。

## 6. 参数与计算步骤对照

| 参数 | 默认与约束 | 作用 |
| --- | --- | --- |
| `clip,super,vectors` | 必需；vectors 为有序正负对 | 输出、当前图像、轨迹场 |
| `blur` | 50.0；binary32 有限 0～200 | 轨迹长度系数 |
| `prec` | 1；int64 先饱和 int32，再要求≥1 | 样本步进密度，增大可减少至无附加点 |
| `thscd1,thscd2` | 400、51.0 | 字段场景判定 |
| `prefix` | `MVUtensils` | 数据名称 |

## 7. 边界、缺失数据与错误

边界回退不读任何字段或 Super。范围内两个字段都验证，一个缺失不能掩盖另一个负 SAD。blur=0 仍验证字段和需要的 Super；轨迹每个点都须在逻辑相位定义范围，不裁短轨迹或跳过非法点。

每方向最多 32768 个附加样本，总数最多 65537。整数 16 位样本和最大不超过 4294967295，可用宽整数准确累加。

## 8. 数值精度与结果确定性

负步进除法向零取整，最终坐标除以 256 向下取整。浮点累加顺序不可改：例如 `[2^60,1,-2^60]` 的 binary64 顺序和为零，另一种顺序可能为 1。只有中心时复制位模式，不用除法改变零符号。
