# Flow：从块向量生成逐像素采样位置

## 1. 这个函数计算什么

`Flow` 先把块向量扩展成每个可见像素的位移，再从一张参考 Super 图像取样。它不平均重叠块，不按 SAD 加权图像，也不在两帧之间混合。

## 2. 计算对象与记号

当前帧 n，参考 `n+d`，pel p，时间系数 `t=trunc(fl64(fl64(time·256)/100))`。每个渲染平面使用自身比例 rx、ry，稠密位移 `Vx,Vy` 单位为该平面的 pel。

## 3. 总体计算流程

验证几何、解码向量并做场景和时间可用性判断；不可用时复制 clip。可用时取得参考 Super 和必要场信息，生成各平面的小向量网格，重采样为稠密场，检查所有实际采样位置，最后复制相位样本。

## 4. 逐步计算

### 4.1 场修正、饱和和色度换算

仅 fields=true、p>1、d 为奇数时启用场修正。当前 top/参考 bottom 为 `f=p/2`，反向为 `-p/2`，其他为零。场奇偶由显式 tff 推算或从两张 Super 的 `_Field` 读取。

先算 `cx=clip(vx,-32768,32767)`、`cy=clip(vy+f,-32768,32767)`，再得到平面小网格：

$$G_x=\lfloor c_x/r_x\rfloor,\qquad G_y=\lfloor c_y/r_y\rfloor.$$

饱和不豁免原始公共向量合法性。负色度位移向下取整，例如 rx=2 时 -1 变 -1，+1 变 0。每个平面独立构造网格，不能先生成亮度稠密场再缩小到色度。

### 4.2 小网格变成稠密场

对 Gx、Gy 分别使用 [整数网格重采样](shared/grid-resampling.md)，传入当前平面的块尺寸、重叠和实际尺寸。14 位系数、几何决定的轴顺序及两轴分别舍入均保留。

例如亮度小网格 `[0,4]`、两个宽 4 的无重叠块，稠密一行 `[0,0,1,2,3,4,4,4]`；rx=2 时先得到色度小网格 `[0,2]`，再得到四个色度位置 `[0,1,2,2]`。

### 4.3 时间缩放和相位选择

对每个平面像素 `(x,y)`：

$$a_x=px+\left\lfloor\frac{V_x(x,y)t+128}{256}\right\rfloor,\quad
a_y=py+\left\lfloor\frac{V_y(x,y)t+128}{256}\right\rfloor.$$

拆为 `qx=floor(ax/p),αx=ax-pqx`，Y 同理，从参考相位 `(αx,αy)` 的 `(hP+qx,vP+qy)` 复制一个样本。时间半值向正无穷舍入；t=128 时 V=1、-1、-3 的偏移分别为 1、0、-1。

这里已经使用 Super 的插值相位，不再次做像素双线性插值。time=0 选参考帧整数相位，仍不是当前帧。

## 5. 一个完整的数值例子

两帧 GRAY8、单个 `8×8` 块、p=1、pad=4、d=1，零向量、SAD=0，场景判断通过。clip[0] 为常量 5，Super[1] 为常量 80。

小网格和稠密位移均为零，所有采样都落在参考整数相位对应位置，输出帧 0 全为 80，time=100 或 0 都一样。帧 1 因参考越界回退到 clip[1]。每帧保留自身 clip 的全部属性。

## 6. 参数与计算步骤对照

| 参数 | 默认与约束 | 作用 |
| --- | --- | --- |
| `clip,super,vectors` | 必需节点 | 输出、参考相位、公共向量 |
| `time` | 100.0；有限 0～100 | 稠密位移缩放 |
| `fields` | false | p>1 且奇数 d 时修正场位移 |
| `thscd1,thscd2` | 400、51.0 | 参考可用性 |
| `tff` | 省略 | 场奇偶来源 |
| `prefix` | `MVUtensils` | 数据命名 |

## 7. 边界、缺失数据与错误

几何和描述匹配要求与 [块渲染](shared/block-rendering.md) 相应部分一致，但 Flow 不在创建时验证整个公共向量域的所有假想采样。创建时验证可见零位移位置，逐帧在生成稠密场后预检所有实际采样点，全部通过才读参考像素。

实际位置越界或落入未定义四分之一相位边缘时报错，不能夹坐标、改相位或返回 clip 掩盖错误。无参考的正常回退无需读取假想场信息。

fields=true、p=1 合法且不启用修正。需要从属性获取场信息时，还需当前 Super；显式 tff 可以从索引推算，通常不必请求当前 Super。time=0 仍验证实际需要的场信息。d=0 合法。

## 8. 数值精度与结果确定性

顺序固定为场修正、16 位饱和、色度向下取整、空间重采样、时间舍入。参考 float32 样本按存储位复制，不归一化、不裁剪。输出属性完整保留 clip，不导出新的稠密向量字段。
