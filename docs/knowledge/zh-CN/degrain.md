# Degrain：从块误差到时间权重和最终像素

## 1. 这个函数计算什么

`Degrain` 为每个块、每个处理平面建立中心帧及多张参考帧的整数权重，按运动向量采样参考，生成加权块，再经过重叠合成和变化限制。向量与误差作为输入读取，不重新估计。

`Degrain1`～`Degrain25` 使用同一运算，名字中的 R 只额外要求恰有 `2R` 个向量成员。通用 `Degrain` 从输入数量推导 R。

这里的块误差指存储的 `AnalysisSAD`，可能包含 SAD、SATD 或 DCT 亮度误差，以及启用的色度 SAD。本函数不重算像素 SAD，也不在度量间换算；现有阈值和缩放公式直接作用于存储值。见[公共分析数据](shared/analysis-data.md)。

## 2. 计算对象与记号

输入顺序 `[a1,b1,…,aR,bR]`，每对偏移互为相反数，绝对距离严格递增。每对哪种符号在前都可以，不会按符号重新排序。中心样本为 `C`，参考样本为 `Rr`，最终权重为 `Vc,Vr`，总和严格为 256。

例如偏移 `[-1,+1,+4,-4]` 合法；`[1,-1,1,-1]` 距离未增加，`[1,-2]` 不对称，均非法。

## 3. 总体计算流程

验证配对、公共几何与参考可用性；生成每对、每平面的误差阈值；将块误差转换为可靠度并结合用户系数归一化；按向量采样和时间加权；合成重叠块；最后限制相对中心样本的变化。

## 4. 逐步计算

### 4.1 近端和远端阈值

`thsad` 与 `thsad2` 分别提供亮度/色度的近、远阈值，均先用 [S](shared/block-rendering.md) 换算到分析误差尺度。包括没有处理的平面和 R=1 不使用的远端值，所有缩放值都必须在 `0…2147483646`。

对第 j 对，R=1 或 j=1 时用近端值。其余按余弦平滑连接：

$$\theta_j=(j-1)\pi/(R-1),\quad a_j=(1-\cos\theta_j)/2,$$
$$T_j=\lfloor T_{near}+a_j(T_{far}-T_{near})+0.5\rfloor.$$

运算逐次 binary64 舍入。插值依据 **对的序号**，不依据真实帧距离。三对阈值 100 到 300 得 100、200、300，距离为 1、4、10 与 1、2、3 没区别。远端值也允许小于近端值。

### 4.2 块误差变成可靠度

可用参考的总块误差为 s，当前平面对应该对的阈值为 T：

$$w(s,T)=\begin{cases}0&s\ge T\\
trunc\left(\frac{256(1-(s/T)^2)}{1+(s/T)^2}\right)&s<T.
\end{cases}$$

第二分支按 binary64 依次计算比值、平方、分子、分母及商。不可用参考直接 w=0。T=0 总走第一分支，不发生除零。各平面都使用同一个存储的总 SAD，只是阈值可不同，没有单独的色度 SAD 数组。

T=100 时 s=0、50、100 分别给 w=256、153、0。可靠度随误差变化，并在达到阈值时完全退出贡献。

### 4.3 用户系数的顺序和最终归一化

用户 `weights` 的顺序为 `[aR,…,a1,centre,b1,…,bR]`，与交替排列的 vectors 不同。零基数组 U 中：

$$u_c=U[R],\quad u_{a_j}=U[R-j],\quad u_{b_j}=U[R+j].$$

先形成精确整数和，再算缩放因子：

$$Z=256u_c+1+\sum_r w_ru_r,\quad g=fl64(256/Z),$$
$$V_r=trunc(fl64(fl64(w_ru_r)g)),\quad V_c=256-\sum_rV_r.$$

分母中的 `+1` 是计算的一部分；中心接收参考取整后的剩余权重，不单独按比例取整。所有用户系数为零时，仍有 Z=1，最终中心 256。中心用户系数为零也不保证最终中心权重为零。

### 4.4 采样与块内加权

中心取 `Super[n]` 的整数相位。每个可用参考按未经时间缩放、未经场修正的输入向量采样，坐标规则见 [块渲染](shared/block-rendering.md)。不可用参考数学上令 `Rr=C,Vr=0`，无需取其图像。

整数块样本为：

$$q=\left\lfloor\frac{128+V_cC+\sum_rV_rR_r}{256}\right\rfloor.$$

权重在当前块、当前平面内不随像素变化。float32 从 `fl32(C·Vc)` 起，按 vectors 顺序累加 `fl32(Rr·Vr)`，每次加法舍入，最后除以 256；不加 128，不裁剪。零权重项仍有规定的浮点算术意义，例如可能改变零的符号。

### 4.5 合成后限制变化

先把已经舍入的块按 [重叠窗口](shared/block-rendering.md) 合成可见像素 q，再相对当前 Super 的整数相位 C 使用 limit。

limit 转成 binary32，任何非有限值都禁用限制；有限值必须大于零。整数输出若 limit≥样本最大值 M，也禁用。否则 `L=trunc(fl32(limit+0.5))`：

$$out=\min(\min(M,C+L),\max(\max(0,C-L),q)).$$

正的小 limit 可舍入为零，得到中心值。float32 对所有有限正 limit 都计算 `lo=fl32(C-limit),hi=fl32(C+limit)` 并夹 q，不把大于 1 的 limit 当作禁用；端点必须有限，区间内保留 q 的零符号。

## 5. 一个完整的数值例子

GRAY8 一个无重叠 `8×8` 块，R=1，两个参考均可用且 SAD=0，默认阈值和全 1 用户系数。两个可靠度都为 256，所以 `Z=769`，两个参考权重各为 85，中心为 86。

中心 100，参考 80、140：

$$q=\lfloor(128+86\cdot100+85\cdot80+85\cdot140)/256\rfloor=107.$$

无重叠且默认无限 limit，结果为 107。若 limit=2.2，L=2，最后得到 102。若只剩 80 的参考可用，权重改为参考 127、中心 129，未限制结果为 90。

所有参考都不可用时中心权重为 256，但仍执行块合成和 limit。中心来自 Super；未处理平面和所有输出属性来自 clip，两者像素可以不同。

## 6. 参数与计算步骤对照

| 参数 | 默认与约束 | 计算作用 |
| --- | --- | --- |
| `clip,super,vectors` | 必需；vectors 为 2～50 个偶数成员 | 输出、样本和配对分析场 |
| `thsad` | `[400,400]`；非负 int64 | 每平面近端阈值 |
| `thsad2` | 有效 thsad | 远端阈值 |
| `planes` | 省略/空为全部实际平面 | 处理哪些平面，未处理平面复制 clip |
| `limit` | 两个正无穷 | 合成后的变化限制 |
| `thscd1,thscd2` | 400、51.0 | 参考场景可用性 |
| `weights` | `2R+1` 个 1 | 用户系数与归一化 |
| `prefix` | `MVUtensils` | 数据命名 |

阈值和 limit 一项复制为亮度/色度两项，空数组使用默认，两项以上报错；U/V 共用色度值。planes 只能为不重复的 0、1、2，格式中不存在的合法平面不处理。weights 不接受空数组，每项先 int32 饱和，再要求 `0≤u≤floor(2147483646/(256(2R+1)))`。

## 7. 边界、缺失数据与错误

逐个验证所有向量成员，即使用户系数为零。每个可用参考都须提供有效 Super；损坏数据或依赖失败不转换成零权重。成员描述除 delta 和正 Levels 外一致，后续合法描述变化仍报错。

所有处理平面在创建时通过整个公共向量域的采样检查。没有实际处理平面也不跳过参数和必需数据验证。没有 fields、time、metric 或搜索参数，这些计算不在 Degrain 中发生。

## 8. 数值精度与结果确定性

可靠度截断、用户权重归一化截断、块内舍入、重叠舍入和最终 limit 是不同阶段，不能合并。参考权重和中心余量严格和为 256。输出帧不依赖前一帧的计算结果。
