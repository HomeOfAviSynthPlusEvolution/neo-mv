# FlowInter：在固定相对时刻合成两帧

## 1. 这个函数计算什么

对每个输出 n，`FlowInter` 选择左帧 n、右帧 n+d，以固定时间比例进行双向运动采样和遮挡感知合成。输出帧数和帧率仍与 clip 相同，不执行输出时间轴重采样。

## 2. 计算对象与记号

vectors 为正负距离配对 `[bw,fw]`，d>0，`l=n,r=n+d`。time 先转 binary32，再算：

$$t=trunc(fl32(fl32(time\cdot256)/100)).$$

这一步与 Flow 使用 binary64 的时间参数换算不同。t 在 0～256。

## 3. 总体计算流程

确定帧对；选主字段和额外字段；生成稠密运动与遮挡；预检并取 Super 相位样本；按普通或额外公式合成。边界或主字段不可用时按 blend 选择原图混合或左图复制。

## 4. 逐步计算

主字段为 bw[l] 与 fw[r]。FlowInter 始终尝试额外字段 bw[r] 与 fw[l]，没有 extramask 参数。完整的选择、坐标和合成公式见 [双向插值](shared/bidirectional-interpolation.md)。

可用路径只读取 Super[l]/Super[r]，额外字段不增加图像时间距离。所有实际平面都处理，分析没有色度不使渲染跳过色度。

边界越界或主字段不可用时，blend=true 用 clip[l] 与 clip[min(r,Nv-1)] 按 t 混合；blend=false 复制 clip[l]。所有分支属性均来自 clip[l]，不改时长属性。

time=0 或 100 不直接跳过运动计算：仍需验证主/额外字段、所选模式的全部采样位置，并执行对应公式。端点不等价于无条件复制输入。

## 5. 一个完整的数值例子

三帧 GRAY8、单个 `8×8` 块、无重叠、p=1、pad=4、d=1。n=0，两个主向量为零、SAD=0，两个额外场只有元数据而无数组。time=50 得 t=128。

主场可用、额外场不可用，选普通模式。零向量无收敛事件，mB=mF=0；若 Super[0]=10、Super[1]=21，主样本 A=10,C=21，得到 U=11,V=22，输出 `floor((11·128+22·128)/256)-1=15`。属性来自 clip[0]，即使它的可见像素不等于 10。

最后一帧 r 越界，blend=true 将最后原图与自身混合；blend=false 精确复制它。

## 6. 参数与计算步骤对照

| 参数 | 默认与约束 | 作用 |
| --- | --- | --- |
| `clip,super,vectors` | 必需；vectors 恰为 `[bw,fw]` | 输出、左右样本、字段 |
| `time` | 50.0；binary32 后有限 0～100 | 固定相对时间 |
| `ml` | 100.0；binary32 后有限正数 | 遮挡事件强度 |
| `blend` | true | 主场不可用时混合原图 |
| `thscd1,thscd2` | 400、51.0 | 字段场景判定 |
| `prefix` | `MVUtensils` | 数据名称 |

## 7. 边界、缺失数据与错误

边界先于逐帧向量读取；在范围内两个主字段都验证，一个缺失不能掩盖另一个损坏。主场不可用时不读额外场。额外场缺失选普通模式，但损坏时报错。必需 Super 或采样失败不变成原图混合。

## 8. 数值精度与结果确定性

时间先 binary32 量化，位移用无偏置 floor，遮挡最大值为 255，整数 H 的偏置为 256。这些量分别有自己的尺度。每个输出独立，不积累前一帧运动状态。
